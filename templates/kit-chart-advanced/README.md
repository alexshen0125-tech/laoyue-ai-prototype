## 用处

供履约分析人员挑选适合指标口径的图形；图形是纯SVG示意，真实页面应提供数据来源和业务阈值定义。

## 用法

1. 解压后双击 index.html，从左侧搜索目录定位组件。
2. 用顶部主题色、圆角、明暗对照外观；每项提供业务状态、交互矩阵和三档尺寸。
3. 一键复制 HTML 得到静态结构和样式；完整行为需要一起迁移 render/mount 与依赖。
4. 一键复制组件提示词可带走该项的用途、限制与状态规范。
5. 顶部免费下载读取同目录 kit-chart-advanced.zip。

## AI 提示词

### 制作履约图表画廊

比较图形表达时。

使用纯内联SVG实现双轴、堆叠、分组柱、散点、热力、事件标注、履约阈值线七种图。每图提供至少五个不同样本以及可展开的原始数据表；坐标单位、图例和轴域清晰。支持键盘选点和图例控制、错误恢复、三档尺寸及主题变量，保留标准画廊复制功能。交付离线单文件HTML与图形选择表，不引入绘图库。

### 组装履约分析页

将指标用于运营复盘时。

基于附件组件创建{{业务名称}}的{{页面类型}}，区分订单单量、距离公里与履约分钟。双轴明确左右单位，热力固定色阶，堆叠总量可以由分项核对。履约阈值来自用户输入，异常点提示只表示相关性；准备空数据与读取失败状态。输出完整纯SVG离线HTML和指标口径表。

### 扩展图表风险规则

需要新增分析维度时。

为{{组件名称}}补充{{状态清单}}，围绕履约阈值说明参考线、事件日期、离群点与缺测样本的表达。隐藏系列时维持固定轴域；不可用颜色单独传递含义；所有点可从表格查值。沿用section结构和CSS变量，提交单文件离线HTML、键盘规则和边界数据验算表。
