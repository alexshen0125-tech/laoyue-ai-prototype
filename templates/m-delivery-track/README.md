# 配送追踪

打开 index.html 即可离线使用，支持深浅主题、做法搜索、状态快照、提示词复制、HTML复制与模块ZIP下载。

## 运单轨迹时间轴

用扫描事件展示包裹经过的节点，预计时间和实际扫描明确区分。

什么时候用：客服需要解释当前包裹位置和下一站。

什么时候别用：扫描轨迹不是车辆实时GPS位置。

状态：包裹运输中 / 节点扫描滞后 / 轨迹已刷新 / 包裹已签收

操作：刷新运单轨迹。刷新只核对离线扫描记录，不把11:30预计时间显示成签收事实。

## 配送延误响应

按承诺窗口识别延误，联系站点时带上时效差距与货品约束。

什么时候用：客服发现订单可能超时，需要发起站点核查。

什么时候别用：尚未超过承诺窗口不能直接承诺延误赔偿。

状态：预计即将超时 / 尚未到承诺时限 / 站点核查已登记 / 收件人已获解释

操作：登记站点延误核查。DL1111与DL1112尚未超时，不允许按逾期登记核查。

## 收货时间改约

在末端派送前选择可用时间段，冷藏件优先限制长时间改约。

什么时候用：收件人短时不在家，需要和站点确认新交付窗口。

什么时候别用：已经签收的包裹不能通过改约重置配送时效。

状态：时间窗口可改约 / 冷藏改约超限 / 改约申请已登记 / 骑手派送中不可改

操作：登记收货改约。仅允许今日窗口，备注至少4字，改约还需站点确认。

## 异常温控处置

把温度读数与货品阈值并列，超温后先隔离复核再决定交付。

什么时候用：冷链配送出现温度告警，需要判断是否继续派送。

什么时候别用：离线阈值仅用于演示，实际按货品和企业规范执行。

状态：温控记录待核 / 读数超出阈值 / 隔离复核已登记 / 复测合格待放行

操作：登记温控处置。温度限制-30至50℃；超出2至8℃先隔离，合格复测也保留原告警。

## 交付凭证与争议

签收记录逐项核对收件身份、时间和包装状态，缺失凭证不直接认定交付完成。

什么时候用：客户反馈未收到或包装破损，需要整理交付证据。

什么时候别用：代收照片不能单独证明货品品质合格。

状态：交付凭证待核 / 签收凭证缺失 / 争议工单已建立 / 交付证据已齐备

操作：建立交付争议工单。客户反馈至少8字才能建立争议工单，运单仍保留待核状态。
