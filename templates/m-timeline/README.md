# 业务时间线 · 交互模块

免费下载 · 双击就能打开 · 复制提示词直接给 AI 用。

> 积木盒 · 老岳AI编辑部 · 原型组 | 单文件 HTML，离线可用 | 2026-11-10

让事件顺序、并行分支、异常原因与历史范围可以追踪。适合产品经理画原型、对齐研发与测试。共5种做法、16个可切换状态。所有数据为示例，不向外部发送。

## 做法与场景

| 做法 | 状态 | 什么时候用 | 什么时候别用 |
|---|---|---|---|
| 按日分组与筛选 | 全部事件 / 只看我 / 无结果 | 操作日志包含多人多天事件 | 只有一个当前状态 |
| 事件详情与变更前后 | 收起 / 展开 / 敏感字段 | 审计时需要知道改了什么 | 将密钥或完整敏感信息放进日志 |
| 并行分支与汇合 | 两支进行中 / 资料完成 / 全部完成 / 物流完成 | 物流与资料校验等可以并行 | 实际有严格前后依赖却画并行 |
| 异常节点与处置 | 失败 / 处理中 / 恢复成功 | 业务事件失败但需要继续追踪 | 直接覆盖或删除失败记录 |
| 历史加载与定位 | 首批 / 加载失败 / 全部历史 | 日志较长需渐进加载 | 要求一次展示完整导出的审计报表 |

## 用法

1. 下载 `m-timeline.zip` 并解压，双击 `index.html`，无需安装和联网。
2. 左侧搜索或选择做法，右侧切换状态，也可直接填写、勾选和点击操作。
3. 顶部可换主题色、圆角和明暗，点击 AI 提示词按钮打开提示词面板。
4. 每种做法可一键复制当前状态 HTML，包含样式与变量。与标杆相同，复制的是外观片段，不含完整交互逻辑；需要交互时复制对应提示词。
5. 示例数据一般仅保存在当前页面内存，刷新重置；主题偏好和反馈邀请的“不再邀请”保存在本机，可在页面恢复。

## 交互与恢复规则

| 做法 | 操作与反馈 |
|---|---|
| 按日分组与筛选 | 筛选更新条数；无结果提供清除入口；标明示例时区。 |
| 事件详情与变更前后 | 展开看前后值，敏感字段始终脱敏，支持收起。 |
| 并行分支与汇合 | 分支独立更新；全部完成才汇合；未完成不得提前发布。 |
| 异常节点与处置 | 保留原始失败，追加处理事件；展示关联编号。 |
| 历史加载与定位 | 追加不覆盖；失败保留已有记录；全部加载后禁用按钮。 |

处理中状态可直接查看，也可以从前一状态操作进入；模拟异步等待约0.65秒。切换做法状态会清理旧计时器。状态选择是演示入口，不代表真实业务后端。
