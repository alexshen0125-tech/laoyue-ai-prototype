# 供应商准入

离线单文件原型，双击 index.html 打开。顶部提供同名zip免费下载。外壳直接采用 m-contract 的 _kit 标准。

## 主体资料核对
核对营业主体的名称、代码与经营范围。
什么时候用：采购准备引入新的供货主体。
什么时候别用：历史供货记录不能替代营业主体核验。
状态：供应主体待建档 / 信用代码格式错误 / 主体信息已核对 / 供应商档案已建立
交互规则：统一信用代码为18位大写字母或数字；名称不得为空。

## 资质到期与补件
逐项展示证照用途和期限，过期证照必须补交。
什么时候用：食品供应商需要持续维护许可材料。
什么时候别用：截图预览不能证明证照真实性。
状态：资质清单待核 / 食品许可已过期 / 资质包可送审 / 资质审核已受理
交互规则：以2026-11-11为基准；食品许可证过期阻止送审。

## 风险评估分层
将高风险主体转入增强调查，避免直接进入普通审批。
什么时候用：采购需要在签约前评估供应稳定性。
什么时候别用：风险评分只是内部演示规则，不能替代信用调查。
状态：风险指标待评估 / 评分输入无效 / 常规尽调可通过 / 触发增强调查
交互规则：风险评分0至100；60及以上进入增强调查。

## 样品试供验收
小批试供记录交期和合格率，确定是否允许扩大采购。
什么时候用：新品引入前验证供应商实际交付能力。
什么时候别用：样品通过不表示量产批次免检。
状态：试供验收待录 / 合格率不达标 / 交期偏差待整改 / 小批试供已通过
交互规则：本次100件；合格率至少98%且准时才可进入试供通过。

## 结算资料与准入
对公账户完成核对后才生成可下单的准入记录。
什么时候用：采购审核完成后开通供应商交易权限。
什么时候别用：个人收款账号不能走对公结算开通。
状态：结算账户待核 / 收款主体不一致 / 准入条件已齐备 / 供应商交易已开通
交互规则：账户名称须与供应商主体一致；不同名退回补正。

## AI 提示词

### 建立主体档案
为{{采购部门}}建立供应商准入页，校验统一信用代码和主体名称，保留经营范围及联系人资料。

### 管理许可续期
为{{供应品类}}展示资质有效期、材料用途和补件路径，过期的食品许可阻断送审。

### 评估准入风险
基于{{供应商}}的风险评分分流常规和增强尽调，再结合试供合格率与对公账户一致性决定交易开通。

数据均为虚构业务记录；操作仅改变当前页面内存，不连接真实系统、不发送消息。状态按钮载入独立样本，重置恢复本做法初始值。
单对象表单不凑五行重复数据；列表各自提供至少五条业务记录。静态HTML复制保留当前预览，完整交互请使用index.html。
