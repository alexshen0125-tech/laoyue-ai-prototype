## 现金实盘与差额
系统应交与现金实盘并列，差额不为零时必须补充能核查的原因。
什么时候用：收银班结束需要确认现金袋金额。
什么时候别用：刷卡和线上支付不应算入现金袋。
交互规则：系统应交1280.50；实盘非负且最多两位小数；有差额需至少8字原因。
状态：现金交班草稿 / 现金差额待说明 / 差额依据已核对 / 现金交接已登记

## 逐项交接待办
五项待办按处理时限排列，接班人签收才改变对应事项的负责人。
什么时候用：下一班需继续处理未完成的到货与客诉。
什么时候别用：已经闭环的事项不应再次作为未完成任务分配。
交互规则：选事项逐项签收；接班人必选；同一事项不能重复签收。
状态：待交接事项清单 / 接班人尚未指定 / 事项已被接班 / 全部事项签收完成

## 紧急异常独立确认
红色异常卡保留冷柜温度与已采取措施，接班前必须确认隔离和升级。
什么时候用：班次交界时仍有食品温控异常。
什么时候别用：普通备注不能代替异常升级与商品隔离。
交互规则：温度9.2℃超出0至4℃；隔离数量1至24；确认主管已通知后才可签收。
状态：温控异常待交代 / 隔离范围不合法 / 主管升级待确认 / 异常责任已接续

## 交接单签收与撤回
交接单发出后等待不同人员接班签收，签收前允许交班人撤回纠错。
什么时候用：纸质交接单需要转成可追溯电子记录。
什么时候别用：交班人不能自行签收完成双人交接。
交互规则：交班人陆青；接班人不可为陆青；待签时可撤回；签完后禁止撤回。
状态：交接单编辑中 / 等待接班人签收 / 交接单已撤回 / 双人签收已完成

## 交接归档与追踪
归档单同时列出已签收事项和未闭环异常，下载后仍可追踪原单号。
什么时候用：门店主管回看上个班次遗留了什么。
什么时候别用：已归档只表示交接完成，不表示异常都已解决。
交互规则：支持HAND-261111-A；未知单号不归档；摘要含未闭环异常。
状态：交接归档查询 / 交接编号不存在 / 签收档案已定位 / 交接摘要已下载
