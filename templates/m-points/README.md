# 会员积分账本

中文离线单文件。打开 index.html；顶部可下载本模块 zip。

## 获取规则试算
消费实付与活动倍率共同决定入账积分，退款商品不参与累计。
什么时候用：会员运营需要验证消费积分类活动的计算口径。
什么时候别用：现金返利不可直接套用积分整数舍入方式。
状态：消费试算 / 积分待入账 / 同单已入账 / 规则参数无效
交互：实付每10元得1分，倍率1至5倍，最终向下取整；订单号防止重复入账。

## 权益兑换
展示会员余额与不同礼品成本，兑换前同时检查积分和库存。
什么时候用：有限库存权益需要给出扣分后的余额。
什么时候别用：实物发货与地址履约应接入订单流程。
状态：权益货架 / 余额不足 / 礼品缺货 / 兑换已扣分
交互：会员初始860分；单次兑换不得超过余额；缺货礼品禁兑。

## 到期批次提醒
积分按获取批次展示到期日，提醒数量来自即将失效的批次。
什么时候用：需要向会员解释哪些积分将在近期过期。
什么时候别用：永久有效积分不应显示虚假的过期倒计时。
状态：积分有效批次 / 七日内到期 / 过期已失效 / 提醒草稿已生成
交互：2026-11-11为演示基准；7天内到期共120分；已到期批次不计可用余额。

## 退款积分冲正
找到原消费流水，再按退款比例计算应冲回积分，避免重复冲正。
什么时候用：订单部分退款后需要撤销相应赠送积分。
什么时候别用：人工奖励不存在退款订单，不走订单冲正。
状态：原流水定位 / 退款金额越界 / 冲正核对 / 积分已冲回
交互：原单实付600元赠60分，退款不得超600；相同原流水仅冲正一次。

## 积分流水追溯
每笔余额变化同时保留来源、增减值与结余，便于回答扣分争议。
什么时候用：客服追查会员积分变化或导出对账资料。
什么时候别用：只展示总余额无法替代逐笔账本审计。
状态：全部流水 / 只看兑换 / 没有匹配记录 / 对账清单已导出
交互：按来源筛选不改余额；导出当前筛选结果；流水号用于查回原始单据。
