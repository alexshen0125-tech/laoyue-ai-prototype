# 用户反馈采集 · 交互模块

免费下载 · 双击就能打开 · 复制提示词直接给 AI 用。

> 积木盒 · 老岳AI编辑部 · 原型组 | 单文件 HTML，离线可用 | 2026-11-10

主动调研的提问、提交、跟进和频控，区别于界面提示。适合产品经理画原型、对齐研发与测试。共5种做法、20个可切换状态。所有数据为示例，不向外部发送。

## 做法与场景

| 做法 | 状态 | 什么时候用 | 什么时候别用 |
|---|---|---|---|
| NPS推荐意愿 | 未选择 / 已评分 / 提交中 / 提交失败 / 已提交 | 用户完成核心体验后采集推荐意愿 | 用户尚未体验或正在处理故障 |
| 事务满意度 | 未评价 / 低分追问 / 高分 / 已提交 | 服务或任务刚完成时 | 跨产品长期忠诚度衡量 |
| 场景内反馈 | 填写中 / 内容错误 / 提交失败 / 已提交 | 用户想反馈当前页面问题 | 主动弹窗索取与当前场景无关的信息 |
| 建议投票与状态 | 未投票 / 已投票 / 已计划 | 公开建议池收集需求信号 | 承诺票数高就必然上线 |
| 邀请频控与退出 | 可邀请 / 稍后提醒 / 不再邀请 / 已恢复 | 非阻断式研究邀请 | 关键业务流程中强制弹问卷 |

## 用法

1. 下载 `m-feedback-collect.zip` 并解压，双击 `index.html`，无需安装和联网。
2. 左侧搜索或选择做法，右侧切换状态，也可直接填写、勾选和点击操作。
3. 顶部可换主题色、圆角和明暗，点击 AI 提示词按钮打开提示词面板。
4. 每种做法可一键复制当前状态 HTML，包含样式与变量。与标杆相同，复制的是外观片段，不含完整交互逻辑；需要交互时复制对应提示词。
5. 示例数据一般仅保存在当前页面内存，刷新重置；主题偏好和反馈邀请的“不再邀请”保存在本机，可在页面恢复。

## 交互与恢复规则

| 做法 | 操作与反馈 |
|---|---|
| NPS推荐意愿 | 0至10分单选，原因选填；不可默认评分；失败保留选择。 |
| 事务满意度 | 1至5分明确端点含义；低分原因选填，不强制拦截。 |
| 场景内反馈 | 问题至少5字；可自愿附带页面信息，默认不附带；失败内容不丢。 |
| 建议投票与状态 | 一人一票可撤回；状态与预计时间分开；不作交付承诺。 |
| 邀请频控与退出 | 稍后本次会话不再出现；不再邀请在本机记忆，可恢复。 |

处理中状态可直接查看，也可以从前一状态操作进入；模拟异步等待约0.65秒。切换做法状态会清理旧计时器。状态选择是演示入口，不代表真实业务后端。
