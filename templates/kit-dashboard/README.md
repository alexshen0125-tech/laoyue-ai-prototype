## 用法

1. 解压后双击 index.html，无需安装或网络。
2. 顶部切换主题色、圆角和明暗；目录搜索组件。
3. 切换状态并操作组件；每项支持一键复制 HTML 和一键复制提示词。
4. 复制 HTML 含样式与当前状态，用于静态原型；交互请连同原文件的 render / mount 迁移，或将提示词交给 AI 实现。

## 返工与使用说明

默认打开每个组件的状态矩阵，并排比较默认、悬停、按下、禁用、出错、加载及小中大尺寸，业务分支仍可单独切换。矩阵中的控件可独立操作。

每组件均提供适用边界、替代方案和专属提示词。页面提示词面板按业务组件列出生成要求。复制 HTML 为静态展示片段；完整交互请保留 index.html 中对应 render / mount 与公共辅助函数。

示例数据不连接业务服务。主按钮随可见区域保留一个，其余操作为次按钮。所有资源内联，无需联网。
