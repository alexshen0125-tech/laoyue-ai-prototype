这是一页能点的「日历与日程」做法合集：6 种做法 18 个状态，每种都能切状态、能真实操作。6 种日期与日程做法：不可选的说原因、区间天数系统算、满了推荐最近可约、冲突给空闲时段。日期以 11月10日 周二为「今天」演示，均为示例。 挑一种，复制 HTML 粘进你的原型；或者复制提示词，让 AI 改成你的业务。

## 一、用处

| 项 | 说明 |
|---|---|
| 解决什么 | 日期时间交互最常见的坑：不可选日期不说原因、区间要来回切两个日历、天数让人自己数、约满了只写「已满」、时间冲突到保存才报、通知被关了还显示「已开启提醒」 |
| 适合谁 | 要画预约、排班、会议室、课表、报表时间筛选的产品经理 |
| 和页面模板的关系 | 页面模板是整页；模块是其中一块的多种做法（预约类页面模板 c-booking = 日历与日程 + 表单 + 支付与结算） |

## 二、做法清单

| # | 做法 | 状态 | 什么时候用 | 什么时候别用 |
|---|---|---|---|---|
| 1 | 日期选择 | 默认 / 已选日期 / 有不可选日期 | 预约日期、截止日期、出生日期以外的大多数单日选择。 | 选生日这类离今天很远的日期（用年月日三个下拉或直接输入更快）；不可选日期不说原因。 |
| 2 | 区间选择 | 快捷选项 / 选择中 / 已选区间 | 报表时间范围、请假、酒店入住离店、活动起止。 | 开始和结束拆成两个独立日历让人来回切；不给快捷项让人每次都点两下；不显示一共几天。 |
| 3 | 日 / 周 / 月视图 | 日 / 周 / 月 / 当天没有日程 | 排班、会议、课表、门店预约后台。 | 只有月视图却塞满文字看不清；不标「现在」；没有日程时显示一整片空格子。 |
| 4 | 预约时段 | 可约 / 部分约满 / 当天约满 | 到店服务、看房、体检、课程试听这类按时段排队的预约。 | 把满了的时段直接藏掉让人以为没开放；当天约满只写「已满」不给下一个可约日；时段太细一屏放不下。 |
| 5 | 冲突提示 | 无冲突 / 有冲突 | 会议室、排班、多人日程，同一个人或同一资源不能同时两件事。 | 保存时才弹「时间冲突」不说和谁冲突；冲突就禁止保存（有时用户就是要重叠）。 |
| 6 | 提醒设置 | 默认 / 自定义 / 系统通知已关闭 | 预约、会议、待办等需要到点提醒的场景。 | 默认不提醒；只给「提前 N 分钟」输入框让人自己填；系统通知被关了还显示「已开启提醒」。 |

## 三、用法

1. 下载文件夹，双击 `index.html`。
2. 左侧目录点到想要的做法，点「状态」切换，演示区里可以真实操作。
3. 右上角换主题色、圆角、明暗，所有演示实时跟着变。
4. **一键复制 HTML**：复制当前状态的 HTML，自带所需 CSS 变量和样式，粘进任意 HTML 原型就能显示（交互逻辑用提示词让 AI 补）。
5. **一键复制提示词**：每种做法一条，交给 AI 就能做出带全部状态的同款。
