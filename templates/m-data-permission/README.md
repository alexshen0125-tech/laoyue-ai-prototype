# 数据权限与行列控制

中文离线单文件，打开 index.html；顶部下载同名zip。保留主题、目录搜索、静态HTML与提示词复制。

## 区域行权限预览
按登录角色所属区域裁剪订单，空区域不获得总部数据。
什么时候用：检查区域经理能否越权看到其他门店。
什么时候别用：集团汇总报表应使用独立的总部角色。
交互规则：华东可见2行、华南1行、总部1行、西南1行；未分配区域0行。
状态：角色区域待选 / 未分配范围拒绝 / 区域订单已过滤 / 跨区访问被拒绝

## 敏感列遮罩
将电话与结算账户分别遮罩，只保留经批准的尾部位数。
什么时候用：客服需要识别账户而不需要完整敏感信息。
什么时候别用：明文核验应经专门授权渠道办理。
交互规则：尾号0至4整数位；固定敏感串按位数生成遮罩；明文访问被拒绝。
状态：遮罩规则草稿 / 尾号参数无效 / 敏感列已遮罩 / 明文读取被阻断

## 导出行数门槛
在导出前计算本次查询结果量，超限时要求收窄业务日期。
什么时候用：审计批量提取记录前验证角色限额。
什么时候别用：分页导出不应被用来规避总量限制。
交互规则：查询固定218行；最大行数1至1000整数；超额不生成下载。
状态：导出任务待检查 / 结果超过角色限额 / 导出范围已核对 / 本地清单已下载

## 限时授权与撤销
授权卡写明访问人、范围和截止时刻，撤销会立即关闭演示访问。
什么时候用：审计人员临时查看指定账单。
什么时候别用：长期岗位权限不适合反复续借临时授权。
交互规则：授权1至24小时；基准11-11 09:00；撤销后保留审计编号。
状态：临时授权申请 / 授权时长不合规 / 审计访问有效 / 临时访问已撤销

## 拒绝优先策略解释
并列展示角色允许与敏感标签拒绝，解释最终裁决来自哪条策略。
什么时候用：同一账单同时命中区域授权和风控封存。
什么时候别用：不能通过提高允许优先级绕过显式拒绝。
交互规则：命中封存标签一律拒绝；普通标签按区域允许；保留裁决轨迹。
状态：策略命中分析 / 封存拒绝生效 / 普通账单允许 / 裁决轨迹已记录
