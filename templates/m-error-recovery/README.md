# 异常恢复 · 交互模块

免费下载 · 双击就能打开 · 复制提示词直接给 AI 用。

> 积木盒 · 老岳AI编辑部 · 原型组 | 单文件 HTML，离线可用 | 2026-11-10

在异常时保住输入、识别已处理结果并给出可执行恢复路径。适合产品经理画原型、对齐研发与测试。共5种做法、19个可切换状态。所有数据为示例，不向外部发送。

## 做法与场景

| 做法 | 状态 | 什么时候用 | 什么时候别用 |
|---|---|---|---|
| 离线操作队列 | 在线 / 离线待同步 / 同步中 / 同步失败 / 已同步 | 低风险编辑允许延迟同步 | 付款或必须实时校验库存的操作 |
| 幂等重试与结果查询 | 结果未知 / 查询中 / 确认未处理 / 已成功 | 提交超时不能确认是否已受理 | 直接重复创建订单或重复付款 |
| 并发编辑冲突 | 发现冲突 / 逐字段选择 / 已合并 | 多人同时编辑同一记录 | 静默覆盖他人更新 |
| 部分成功与失败重试 | 部分失败 / 重试中 / 全部成功 | 批量任务允许每条独立处理 | 必须全部成功或全部回滚的事务 |
| 会话过期与继续 | 已过期 / 验证中 / 验证失败 / 已恢复 | 编辑中登录失效需要恢复 | 敏感输入未经同意长期持久化 |

## 用法

1. 下载 `m-error-recovery.zip` 并解压，双击 `index.html`，无需安装和联网。
2. 左侧搜索或选择做法，右侧切换状态，也可直接填写、勾选和点击操作。
3. 顶部可换主题色、圆角和明暗，点击 AI 提示词按钮打开提示词面板。
4. 每种做法可一键复制当前状态 HTML，包含样式与变量。与标杆相同，复制的是外观片段，不含完整交互逻辑；需要交互时复制对应提示词。
5. 示例数据一般仅保存在当前页面内存，刷新重置；主题偏好和反馈邀请的“不再邀请”保存在本机，可在页面恢复。

## 交互与恢复规则

| 做法 | 操作与反馈 |
|---|---|
| 离线操作队列 | 离线保留内容；恢复网络后手动同步；失败保留待同步项。 |
| 幂等重试与结果查询 | 先查询同一请求编号；确认未处理才重试；展示逻辑处理次数。 |
| 并发编辑冲突 | 并排展示本地与远端值；逐字段选用后确认；保留双方原始值。 |
| 部分成功与失败重试 | 只重试失败项；成功项不再提交；保留逐条原因。 |
| 会话过期与继续 | 先保留本页非敏感输入；模拟验证后恢复；不采集真实密码。 |

处理中状态可直接查看，也可以从前一状态操作进入；模拟异步等待约0.65秒。切换做法状态会清理旧计时器。状态选择是演示入口，不代表真实业务后端。
