# 搜索与发现组件库

免费下载 · 双击就能打开 · 复制提示词直接给 AI 用。

检索工作台 · 原创示例。检索仅在这份离线目录内执行。

## 用处

供采购检索产品的设计师与前端比较查询路径；控件负责输入与召回，整页仍需连接业务目录。

## 用法

1. 解压后双击 index.html，在目录内搜索检索相关控件。
2. 调整检索画廊顶部的颜色、圆角与明暗，比较各查询状态和三种密度。
3. 复制 HTML 得到当前查询控件的静态外观，检索行为需连同 render/mount 迁移。
4. 复制组件提示词可带走召回约束；页面顶部提供检索页组装提示词。
5. 下载入口读取同目录 kit-search.zip。

## AI 提示词

### 从零搭建检索画廊

制作搜索框、键盘联想、筛选胶囊、命中高亮、零结果和检索历史的独立画廊。检索词采用冷藏目录中的食材名称；明确组合条件与清空范围，列表至少五条不同货品。每个组件给出可切换的业务状态、交互矩阵与三档尺寸，支持主题色和明暗调整。提供单文件离线HTML、用途表及逐项复制能力。

### 组织货品检索页

基于附件组件搭建{{业务名称}}的{{页面类型}}，以检索词驱动冷藏货品目录，保留用户原输入并显示匹配数量；空白不等于零命中。联想用上下键、Enter和Escape，清除筛选时仍保留查询。展示等待、索引失败和结果加载完毕，交付无外部依赖的页面与交互说明，未知字段不要编造。

### 增加搜索专属控件

扩展{{组件名称}}，以{{状态清单}}细分检索词的拼写纠正或同义词召回；必须解释为什么推荐、接受后如何更新输入以及如何撤销。沿用当前搜索画廊section与CSS变量，附具体use/avoid/spec、尺寸对比及键盘规则；给完整离线HTML和召回规则表。
