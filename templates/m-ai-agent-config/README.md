# Agent配置与权限

让模型指令、知识范围和工具授权在发布前可检查、可撤回。

离线打开 index.html。示例数据均为虚构；除高级表单草稿外，业务修改仅在本次页面有效。

## Agent职责边界
把任务目标与禁止行为写成可核验的运行指令。
适用：配置内部采购助手的角色范围。
不适用：角色文字不提供系统级权限隔离。
规则：指令至少二十字且包含采购与转人工。
状态：Agent指令草拟、Agent边界不全、Agent职责可存、助手指令已存

## 模型运行限额
同时展示上下文预算与单次最大输出令牌。
适用：管理员为采购助手控制运行成本。
不适用：本地示例不提供实时模型报价。
规则：上下文8192，输出512至4096且不超过上下文。
状态：模型限额待设、输出预算越界、推理限额可用、模型配置已存

## 知识范围绑定
五份内部文档分别展示分级与可检索范围。
适用：Agent需要检索采购制度与操作手册。
不适用：财务密级文档不得混入普通员工助手。
规则：普通员工仅绑定公开与内部文档，薪酬文档阻断。
状态：知识范围待选、知识密级冲突、检索范围可绑、知识授权已绑

## 工具最小权限
逐项说明查询库存与创建采购单的授权差异。
适用：采购助手准备连接业务工具。
不适用：前端勾选不能替代服务端鉴权。
规则：读库存可直接启用；写采购单必须二次人工确认。
状态：工具权限待核、写权限缺确认、最小权限可存、工具授权已存

## 沙盒验证与发布
用五条验收用例检查越权请求和转人工路径。
适用：配置完成需要先做上线前验证。
不适用：沙盒结果不能替代生产安全评估。
规则：全部用例通过才允许发布本地版本，撤回恢复草案。
状态：Agent沙盒待跑、越权用例未过、助手版本可发、Agent版本已发

## AI 提示词

### 从零构建
为{{采购助手}}配置Agent职责和模型限额，输出令牌越界阻断，明确转人工边界。

### 业务迁移
为{{内部Agent}}绑定知识库，按文档密级过滤，普通员工不能读取薪酬材料。

### 补齐边界
为{{工具管理员}}设置Agent读写权限，写工具必须人工确认，通过沙盒后才发布。
