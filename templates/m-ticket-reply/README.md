# 工单回复工作台

中文离线单文件。打开 index.html；顶部可下载本模块 zip。

## 客户可见回复
面向客户的回复带收件身份、正文预览与投递回执，避免内部措辞误发。
什么时候用：客服已经核实情况，需要正式向客户更新处理进展。
什么时候别用：同事间责任讨论应写入内部备注。
状态：回复草稿 / 客户视角预览 / 投递失败 / 回复已送达
交互：正文至少10字；预览内容改变后必须重新核对；断网演示只保留草稿。

## 内部备注与指派
黄色协同区与客户消息分开，备注只交给被指派的处理人。
什么时候用：问题需要仓配或财务同事接手核查。
什么时候别用：内部备注不会通知客户，不能替代公开进度更新。
状态：内部协同草稿 / 处理组未选 / 备注已记录 / 责任人已接单
交互：必须指定处理组并写清待查事项；保存后记录作者与负责组。

## 补充凭证附件
物流破损照片与订单凭证分别展示格式、大小和能否发送的原因。
什么时候用：回复需要引用一份客户可读的证明材料。
什么时候别用：包含完整身份证或支付密码的文件不可向外发送。
状态：等待凭证 / 文件格式不符 / 附件待发送 / 附件已附入草稿
交互：仅支持PNG、JPG、PDF且不超过5MB；本地选文件只读取元信息。

## 定时回复与撤销
给夜间草稿安排次日发送时间，并显示发送前可撤销的窗口。
什么时候用：非紧急回复需避开客户休息时段。
什么时候别用：安全事故与紧急投诉不应延后处理。
状态：安排发送时刻 / 发送时间已过 / 排期已建立 / 排期已撤销
交互：基准为2026-11-11 18:00；计划必须晚于基准，排期不代表真实投递。

## 回复后结单
按问题解决、等待凭证或持续争议给出不同的工单归宿。
什么时候用：处理结束需要说明结单依据并保留重新打开入口。
什么时候别用：客户未回复不能直接认定问题已经解决。
状态：等待处理结论 / 等待客户凭证 / 争议继续跟进 / 工单已结单 / 工单重新打开
交互：只有客户确认解决才允许结单；等待材料保留开放；重新打开保留历史。

所有业务均在页面内存模拟；重置仅影响当前做法。切换状态载入独立预览，状态图不代表真实服务结果。主题、搜索、提示词和静态HTML复制沿用公共外壳。
