# 通知与收件组件库

免费下载 · 双击就能打开 · 复制提示词直接给 AI 用。

消息值班台 · 原创示例。仅更新当前演示收件箱；刷新后回到初始消息。

## 用处

供消息产品设计与前端比较通知触达、阅读和收尾方式；这些控件可以拼成收件页，接入服务端时需重新校验权限和同步语义。

## 用法

1. 解压后双击 index.html，从左侧搜索目录定位组件。
2. 用顶部主题色、圆角、明暗对照外观；每项提供业务状态、交互矩阵和三档尺寸。
3. 一键复制 HTML 得到静态结构和样式；完整行为需要一起迁移 render/mount 与依赖。
4. 一键复制组件提示词可带走该项的用途、限制与状态规范。
5. 顶部免费下载读取同目录 kit-notification.zip。

## AI 提示词

### 搭建收件组件画廊

设计通知触达规则时。

制作离线通知组件库，包含通知中心、未读红点、通知类别切换、免打扰和批量已读。用五条不同订单或审批消息演示，标明已读只代表阅读。每项提供业务状态、真实控件交互矩阵、小中大尺寸、use/avoid/spec和复制HTML；所有颜色由CSS变量驱动，保留顶部下载和三条提示词。交付单文件HTML与组件说明表。

### 拼装值班消息页

把入口和收件箱连起来时。

使用附件index.html为{{业务名称}}制作{{页面类型}}。围绕通知类别组织收件箱，打开摘要才标已读，计数随列表改变；免打扰区分跨日时间和紧急例外。覆盖空收件箱、同步中与读取失败，禁止把阅读动作描述成业务处理完成。未知数据明确标记，交付完整离线HTML和事件反馈表。

### 扩展消息偏好项

需要更多触达方式时。

给{{组件名称}}增加{{状态清单}}，围绕通知类别配置站内、声音与桌面提醒的独立偏好。解释权限拒绝后的降级、保存失败如何保留草稿，以及撤销范围。按现有section注册，补use/avoid/spec、键盘操作、三档密度与CSS变量；输出可复制的离线HTML和偏好状态映射。
