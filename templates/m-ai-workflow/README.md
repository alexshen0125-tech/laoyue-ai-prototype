# AI 工作流编排

离线单文件原型，双击 index.html 打开。顶部提供同名zip免费下载。外壳直接采用 m-contract 的 _kit 标准。

## 节点连线与发布
按输入、检索、生成、审核、输出核对五个节点的依赖。
什么时候用：搭建需要人工复核的知识问答链。
什么时候别用：单次聊天无需维护发布版本。
状态：编排草稿 / 审核节点缺失 / 拓扑校验通过 / 工作流版本已发布
交互规则：缺少审核节点阻断发布；恢复后形成版本快照。

## 变量映射与缺参
把工单字段绑定到模型输入，避免把客户标识当问题正文。
什么时候用：上游工单结构与下游提示模板不同。
什么时候别用：无需转换的固定文本不必配置映射。
状态：字段映射待补齐 / 正文来源为空 / 脱敏映射已预览 / 输入契约已保存
交互规则：必填映射不能为空；试运行仅展示脱敏输入。

## 检索阈值与证据
同时展示文档得分和是否进入上下文，分离低相关证据。
什么时候用：知识库结果需要控制引用质量。
什么时候别用：没有来源的内容不能通过放宽阈值充当证据。
状态：召回结果待筛 / 阈值过高无证据 / 引用集合就绪 / 证据集已锁定
交互规则：阈值0至1；至少命中一篇才可锁定证据集。

## 模型预算与超限
以固定本次输入量核对预算，超限后保留待处理请求。
什么时候用：运营团队限制单次模型消耗。
什么时候别用：这里的令牌估算不能作为真实账单。
状态：预算等待核对 / 令牌额度不足 / 调用预算允许 / 模型执行已模拟
交互规则：令牌预算为100至8000整数；本次需1240令牌。

## 人工审核与恢复
在高风险答复处暂停执行，记录意见后继续输出。
什么时候用：涉及赔付承诺的自动答复需要负责人确认。
什么时候别用：无人值守场景不能假定审核自动通过。
状态：赔付答复待审 / 审核意见不足 / 草稿退回改写 / 审核通过并续跑
交互规则：意见至少8字；退回保留草稿；通过后只继续一次。

## AI 提示词

### 设计节点依赖
为{{售后团队}}编排工作流，按节点名称明确输入、检索、生成、人工审核与输出；缺少审核闸门阻断发布。

### 核对引用证据
为{{知识库}}设计检索阈值配置，逐文档显示得分、版本及引用段落，无命中文档时不得生成事实性结论。

### 限制模型费用
围绕{{模型}}的令牌预算展示输入量、输出预留和超限分支，加入人工续跑记录与单次执行锁。

数据均为虚构业务记录；操作仅改变当前页面内存，不连接真实系统、不发送消息。状态按钮载入独立样本，重置恢复本做法初始值。
单对象表单不凑五行重复数据；列表各自提供至少五条业务记录。静态HTML复制保留当前预览，完整交互请使用index.html。
