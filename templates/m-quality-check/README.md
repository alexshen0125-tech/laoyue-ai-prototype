# 质检抽检

离线单文件原型，双击 index.html 打开。顶部提供同名zip免费下载。外壳直接采用 m-contract 的 _kit 标准。

## 批次抽样计划
对入库箱数计算最低抽检量并锁定取样方案。
什么时候用：仓库收货后安排到货质量检查。
什么时候别用：全检物料不应缩减为抽样计划。
状态：批次待抽样 / 样本数量不足 / 抽样方案合格 / 取样单已锁定
交互规则：批量260箱，最低抽13箱；数量须为1至260整数。

## 缺陷分级记录
把包装、标签与异物风险分开记录，严重缺陷直接隔离。
什么时候用：抽样过程中发现不同性质的不合格项。
什么时候别用：未经检验不要以外观推断食品安全。
状态：缺陷待判级 / 缺陷说明不足 / 一般缺陷待返工 / 重大缺陷已隔离
交互规则：重大缺陷触发隔离；一般缺陷进入返工；说明至少6字。

## 计量判定
对净含量测量值逐件标注偏差，保留设备校准信息。
什么时候用：定量包装到货需检查重量下限。
什么时候别用：不同规格重量不能套用本批阈值。
状态：计量结果待录 / 重量低于下限 / 五件计量合格 / 计量记录已归档
交互规则：本批下限495克；录入第五件，低于下限判不合格。

## 返工与复检
返工责任方提交措施后重新登记复检结论。
什么时候用：包装返修完成后验证改进是否有效。
什么时候别用：重大食品安全问题不能用本地复检自行解除隔离。
状态：返工等待措施 / 返工措施不完整 / 复检仍未通过 / 复检通过待放行
交互规则：返工措施至少8字，复检不通过则保持冻结。

## 批次放行签核
用未结缺陷数约束放行，并给出仓储可执行的结果。
什么时候用：质检负责人决定批次是否可进入可售库存。
什么时候别用：销售紧急需求不能覆盖未关闭质量缺陷。
状态：放行证据待核 / 尚有缺陷未结 / 质量负责人待签 / 批次已准予入库
交互规则：存在未结缺陷禁止放行；五项证据齐全才进入签核。

## AI 提示词

### 安排抽样
为{{仓库}}的批次号设计抽样数量输入，按到货箱数计算最低样本，覆盖不足禁止签发取样单。

### 界定缺陷
为{{品类}}建立缺陷等级与处置矩阵，重大问题隔离库存，一般包装缺陷创建返工单并指定责任人。

### 验证放行
围绕{{检验批}}的批次号串联计量记录、返工措施和复检结果，有未结缺陷时禁用放行签核。

数据均为虚构业务记录；操作仅改变当前页面内存，不连接真实系统、不发送消息。状态按钮载入独立样本，重置恢复本做法初始值。
单对象表单不凑五行重复数据；列表各自提供至少五条业务记录。静态HTML复制保留当前预览，完整交互请使用index.html。
