# 课程播放与进度

打开 index.html 即可离线使用，支持深浅主题、做法搜索、状态快照、提示词复制、HTML复制与模块ZIP下载。

## 章节续学

按章节恢复学习位置，进度只随实际完成的阅读片段增加。

什么时候用：学员离开课程后返回，需要接着上次内容学习。

什么时候别用：正式视频计时需接播放器事件，不能用按钮代替学时证明。

状态：断点可续学 / 章节阅读中 / 本节已完成 / 后续章节锁定

操作：完成本节并继续。完成第二节后进度从1/5更新为2/5，第三节进入可学习状态。

## 播放偏好与字幕

让字幕、语速和画质分别可调，弱网模式优先保留讲解内容。

什么时候用：学员需要调节可读字幕或减少移动流量消耗。

什么时候别用：此离线界面不包含音视频源，不能用于真实播放质量测试。

状态：标准播放配置 / 低带宽模式 / 偏好已应用 / 低带宽模式

操作：应用学习偏好。可选择五档语速；英文字幕未发布时拦截应用。

## 时间点笔记

笔记锚定讲解时间，把操作疑问与对应知识片段放在一起。

什么时候用：复习时需要从笔记回到讲义所在的知识点。

什么时候别用：个人笔记不应写入客户订单号等敏感数据。

状态：笔记草稿 / 笔记内容过短 / 时间点已记录 / 笔记仅本地可见

操作：记录时间点笔记。笔记至少6字，以纯文本追加到08:32，不解释为HTML。

## 随堂检查与解锁

用异常处置题核验理解，答对后开放后续的交接实训。

什么时候用：高风险操作课程需要在关键节点检查学习理解。

什么时候别用：单题正确不能代替完整岗位资格考试。

状态：知识点待作答 / 处置顺序错误 / 交接实训已解锁 / 测验尝试已重置

操作：提交随堂答案。仅“隔离货品并复测留证”解锁交接实训，其余答案给出处置反馈。

## 学习进度与凭证

将章节、练习和考核分别记分，证书门槛不会被浏览进度替代。

什么时候用：培训管理员核对个人课程完成条件。

什么时候别用：演示进度导出不具有职业资质认证效力。

状态：学习尚未结课 / 考核分数不足 / 学习清单已导出 / 证书待管理员签发

操作：核验并导出学习清单。分数须为0至100整数，达到80分才可下载非正式学习清单。
