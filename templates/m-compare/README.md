# 选型对比 · 交互模块

免费下载 · 双击就能打开 · 复制提示词直接给 AI 用。

> 积木盒 · 老岳AI编辑部 · 原型组 | 单文件 HTML，离线可用 | 2026-11-10

从候选集合到差异、评分与缺失信息，辅助产品选型。适合产品经理画原型、对齐研发与测试。共5种做法、15个可切换状态。所有数据为示例，不向外部发送。

## 做法与场景

| 做法 | 状态 | 什么时候用 | 什么时候别用 |
|---|---|---|---|
| 候选对比托盘 | 未选择 / 已选两项 / 达到上限 | 列表中挑选二至三个候选 | 候选只有一个或指标不可比 |
| 只看差异 | 全部指标 / 只看差异 / 没有差异 | 指标多且大部分相同 | 所有指标都是独有描述 |
| 以基准方案对比 | 默认基准 / 已换基准 / 同值 | 替换供应商或评估升级方案 | 不同量纲却直接相减 |
| 加权选型评分 | 默认权重 / 已调整 / 权重错误 | 团队能约定明确评分维度 | 不能量化的主观价值或伪精确决策 |
| 缺失与失效候选 | 部分缺失 / 候选失效 / 已补全 | 候选资料不完整或方案已下架 | 用零值代替未知数据 |

## 用法

1. 下载 `m-compare.zip` 并解压，双击 `index.html`，无需安装和联网。
2. 左侧搜索或选择做法，右侧切换状态，也可直接填写、勾选和点击操作。
3. 顶部可换主题色、圆角和明暗，点击 AI 提示词按钮打开提示词面板。
4. 每种做法可一键复制当前状态 HTML，包含样式与变量。与标杆相同，复制的是外观片段，不含完整交互逻辑；需要交互时复制对应提示词。
5. 示例数据一般仅保存在当前页面内存，刷新重置；主题偏好和反馈邀请的“不再邀请”保存在本机，可在页面恢复。

## 交互与恢复规则

| 做法 | 操作与反馈 |
|---|---|
| 候选对比托盘 | 最多三项，至少两项才可对比；可移除后补选。 |
| 只看差异 | 切换只隐藏相同指标，保留候选名称和切换入口。 |
| 以基准方案对比 | 明确基准；席位数越大越好，差值同时显示单位。 |
| 加权选型评分 | 权重合计须为100；评分与公式公开；排名仅供辅助。 |
| 缺失与失效候选 | 未知写待核实；失效不能选定；补齐后再作决定。 |

处理中状态可直接查看，也可以从前一状态操作进入；模拟异步等待约0.65秒。切换做法状态会清理旧计时器。状态选择是演示入口，不代表真实业务后端。
