# 产品引导组件库

免费下载 · 双击就能打开 · 复制提示词直接给 AI 用。

首次使用实验室 · 原创示例。跳过与气泡位置可保存在本机；配置清单和首建数据仅在本轮演示中有效。

## 用处

供新手教学设计者搭建可中断的学习路径；这些独立控件需结合真实页面的目标控件与完成条件。

## 用法

1. 解压后双击 index.html，从左侧搜索目录定位组件。
2. 用顶部主题色、圆角、明暗对照外观；每项提供业务状态、交互矩阵和三档尺寸。
3. 一键复制 HTML 得到静态结构和样式；完整行为需要一起迁移 render/mount 与依赖。
4. 一键复制组件提示词可带走该项的用途、限制与状态规范。
5. 顶部免费下载读取同目录 kit-onboarding.zip。

## AI 提示词

### 生成首次使用工具箱

规划教学路径时。

围绕引导进度构建五类组件：定位气泡、五项配置清单、首建空态、功能发现和跳过恢复。教学以仓库空间设置为原创示例，首次使用和后续推荐分开。每类展示可操作矩阵、禁用、故障恢复、等待、尺寸以及业务分支。沿用附件标准画廊和主题变量，交付无外链单文件HTML、README与交互规范。

### 连接新用户上手页

需要连续教学时。

把附件组件组织为{{业务名称}}的{{页面类型}}，以引导进度串联建立空间、邀请协作者、配置库位、导入货品、检查通知五个节点。允许安全跳过并从离开处恢复，说明本地存储范围。空态给出唯一首建动作，异常时保留输入。交付完整离线HTML和步骤完成条件表，不虚构服务器已保存。

### 补充教学分支

新增角色教学时。

在{{组件名称}}中增设{{状态清单}}，为不同岗位给出独立的引导进度与完成条件。考虑Escape退出后的焦点归还、目标元素缺失的回退、上一步可逆与完成后的再次查看。保留section的use/avoid/spec及尺寸和键盘示范，输出离线HTML与教学分支图的文字说明。
