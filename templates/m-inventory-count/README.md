# 库存盘点

离线单文件交互原型。打开 index.html 使用；下载包包含页面及核验记录。标准外壳沿用 _kit。

## 盘点范围冻结
按库区冻结参与盘点的库位，显示未完成出库任务。
什么时候用：仓库准备开展周期盘点。
什么时候别用：冻结演示不会拦截真实仓库作业。
业务状态：盘点库区待选 / 库区存在未结作业 / 库位可进入冻结 / 盘点范围已冻结
交互规则：冷藏区有未完成出库单；常温区可冻结。

## 盲盘数量录入
隐藏账面量让盘点员先提交实际清点结果。
什么时候用：首盘需要减少账面库存对盘点的影响。
什么时候别用：称重品需先统一计量单位。
业务状态：首盘数量待填 / 清点数量不合法 / 首盘记录可提交 / 盲盘数量已锁定
交互规则：实盘数量为0至9999整数，提交后才展示账面120。

## 账实差异定位
将五个SKU差异并排展示以确定复盘对象。
什么时候用：主管需要选择差异大的物料优先处理。
什么时候别用：单次差异不能直接断定责任归属。
业务状态：账实差异待分类 / 差异原因未选择 / 复盘对象已确定 / 差异复盘已派发
交互规则：咖啡豆账面120，实盘116；必须选择差异原因。

## 双人复盘确认
对照首盘与复盘数量，要求第二人独立签认。
什么时候用：高价值商品有明显数量差异。
什么时候别用：同一盘点员不能替代独立复核。
业务状态：复盘数量待核 / 两次盘点不一致 / 复盘结果可签认 / 双人复盘已确认
交互规则：首盘116；复盘须一致且复核人为周遥。

## 库存调整留痕
记录调整理由和账面变化，避免无依据抹平差异。
什么时候用：已确认差异需要形成调整凭证。
什么时候别用：未审批调整不能当作实仓入出库。
业务状态：库存调整待说明 / 调整依据不充分 / 调整凭证可生成 / 盘点调整已留档
交互规则：调整从120到116，理由至少12字。

## AI 提示词

### 冻结盘点库区
为{{仓库}}选择库位范围，显示未结作业，在冻结前处理出库冲突。

### 设计盲盘复核
为{{商品类别}}录入实盘数量，首盘后显示差异，第二盘点人独立签认。

### 解释库存调整
围绕{{盘点单}}的差异分类与复盘证据，生成库位库存调整记录。
