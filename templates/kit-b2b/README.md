## 用处

适合产品、设计和前端复用独立交互；组件可组合成模块，再用于完整页面。

业务规则：退回必须有原因；归档不可修改；日志保留前后值；敏感字段不下发给无权限角色；批量重试不重复处理成功项。

## 用法

1. 解压后双击 index.html，离线可用。
2. 目录搜索并切换组件状态，顶部调整主题色、圆角及明暗。
3. 一键复制 HTML 获取含变量和样式的当前静态片段；完整交互需连同对应 render/mount 及辅助函数迁移。
4. 一键复制提示词可将交互要求交给 AI；顶部面板支持就地填写变量。
