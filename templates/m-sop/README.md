# 标准作业流程

将作业版本、关键动作、偏差和复核签认串成可执行的班次SOP。

离线打开 index.html。示例数据均为虚构；除高级表单草稿外，业务修改仅在本次页面有效。

## 作业版本领用
并列展示五条作业规范的生效日期和替代关系。
适用：班组开始冷链收货前领用规范。
不适用：历史失效版本只允许追溯。
规则：仅2026.11版可领用，旧版必须切换。
状态：作业版本待选、作业版本失效、当前版本可领、班次版本已领

## 开工条件检查
把温度计校准与防护准备作为进入作业的条件。
适用：冷链验收需要先确认设备状态。
不适用：准备勾选不能替代实际校准记录。
规则：校准和防护两项均须确认。
状态：开工条件待核、开工准备未齐、开工条件具备、收货作业已开

## 测温步骤执行
按探针测温顺序记录当前到货核心温度。
适用：验收员逐批执行冷藏收货。
不适用：冷冻货品需要独立的温区标准。
规则：允许0至8摄氏度，越界进入偏差处理。
状态：到货温度待录、核心温度越界、收货温度合格、测温步骤已记

## 作业偏差登记
将隔离处置与异常批号绑定后交给复核人。
适用：发现冷链温度超标需要暂停入库。
不适用：不能直接销毁未经认定的货物。
规则：异常批号固定LOT-711，处置至少十字。
状态：异常批次待说明、隔离依据不足、偏差措施可送、偏差记录已送

## 班次复核签认
区分执行人和复核人，确认关键记录完整。
适用：班次结束需要独立检查作业留痕。
不适用：执行人不能替自己完成第二人签认。
规则：执行人林岚，复核人须选周遥。
状态：班次签认待核、复核人员重复、独立复核可签、标准作业已归档
