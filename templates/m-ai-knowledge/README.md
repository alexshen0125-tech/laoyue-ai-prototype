# 知识库文档与切片

中文离线单文件，打开 index.html；顶部下载同名zip。保留主题、目录搜索、静态HTML与提示词复制。

## 固定长度切片
使用一段完整配送手册计算实际字符区间，每张切片可回看原文。
什么时候用：确认短文档适合哪种固定窗口。
什么时候别用：字符窗口不等同于模型token窗口。
交互规则：长度10至100整数；按实际字符串切片，最后一段可不足窗口。
状态：切片长度草稿 / 字符窗口越界 / 文档切片已预览 / 切片方案已采用

## 重叠窗口上下文
相邻窗口重复一部分原文，展示步长与重复区间的实际关系。
什么时候用：关键规则常跨越两个切片的边界。
什么时候别用：过高重叠会重复召回大量相同句子。
交互规则：窗口固定30字符；重叠0至29；步长为30减重叠；列出实际分片。
状态：重叠方案草稿 / 重叠不能大于窗口 / 相邻窗口已生成 / 上下文参数已锁定

## 关键词命中原文
只对演示文档做精确关键词匹配，结果直接展示对应政策原句。
什么时候用：问答管理员核对引用能否在知识原文找到。
什么时候别用：此页面没有向量模型或语义相关度服务。
交互规则：检索词非空；五段政策实际匹配；未命中不补写答案。
状态：检索词待输入 / 检索词为空 / 原文命中列表 / 没有匹配片段

## 索引版本重建
旧版本继续提供查询，新文本切片完成后才替换当前服务版本。
什么时候用：配送政策改版需要重建离线索引预览。
什么时候别用：不要在新版本未检查时删除当前可用版本。
交互规则：当前v2；目标版本大于2；新文至少20字；先构建再切换。
状态：知识v2服务中 / 重建版本不合法 / 新版本等待切换 / 新索引版本已启用

## 团队访问前置过滤
先按业务团队裁剪文档目录，再允许查看对应片段。
什么时候用：同一知识库同时存客服政策和采购协议。
什么时候别用：前端目录过滤只是演示，真实检索必须服务端校验。
交互规则：客服只能查看配送手册，采购可看供应商协议；不匹配拒绝预览。
状态：文档访问待检查 / 团队无权读取 / 授权原文可预览 / 访问记录已登记
