# 知识库文档与切片

中文离线单文件原型。打开 index.html；顶部可下载同名zip。

- 固定长度切片：长篇文档按字符窗口拆分。输入范围 100–2000字。
- 重叠窗口：跨段落知识需要保留上下文。输入范围 0–99字。
- 检索预览：查看离线文档中命中片段。输入范围 1–5条。
- 版本重建：修改文档后预览重建索引。输入范围 2–99。
- 访问范围：限定知识适用的业务团队。输入范围 100–999。

每种含5条独立业务记录及默认、待确认、失败与重试、成功、空态。选择记录→填写参数与说明→核对→预览→确认。修改使确认失效；失败保留输入；取消恢复，成功锁定防止重复。状态切换独立加载演示数据。

左侧搜索目录；每种有适用/别用、复制含样式HTML和提示词；顶部3条AI提示词、主题色、明暗、圆角。HTML复制为静态片段，完整交互使用本文件。

数据虚构，配置仅存在页面内存，不发送请求。权限过滤、Webhook签名、语义检索、开关下发、实验统计均未连接服务；成功指本地草稿预览。实验预估采用向下取整，固定分桶仅演示取模，生产需稳定哈希。价格不叠加其他规则，SLA时间为演示等待分钟。知识切片按字符估算，未读取真实文件。

DOM验收见 dom-validation.json。浏览器验收状态见本批进度；未完成渲染验证前不宣称390宽无溢出。无外部脚本/字体/图片。
