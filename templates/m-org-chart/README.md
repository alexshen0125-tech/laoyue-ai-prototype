# 组织架构与人员调动

打开 index.html 即可离线使用，支持深浅主题、做法搜索、状态快照、提示词复制、HTML复制与模块ZIP下载。

## 部门树与编制

沿经营中心展开部门，先看直属团队再决定新增编制的归属。

什么时候用：扩张门店运营团队，需要核查部门层级与预算席位。

什么时候别用：只查个人联系方式时使用通讯录即可。

状态：组织在编 / 编制超额 / 归属已核准 / 部门已停用

操作：核准编制归属。新增1至3个整数席位，扣减区域支持的3个预算余量。

## 跨部门调动

把现任部门与接收岗位并排展示，调动前保留直属经理的确认痕迹。

什么时候用：员工跨中心转岗，且需要明确新的成本归集部门。

什么时候别用：短期借调不应直接覆盖劳动关系所属部门。

状态：调动待拟定 / 生效日期无效 / 调令已登记 / 生效日未到

操作：登记调令。调令生效日须在2026-11-11之后，登记前仍归属原成本中心。

## 汇报线调整

新经理的下属链先做循环检查，再写入员工的实线汇报关系。

什么时候用：管理跨度变化，需要调整直属经理而不迁移部门。

什么时候别用：项目协作的虚线关系请另建项目成员表。

状态：汇报链待检 / 检测到循环 / 新经理已关联 / 经理已离职

操作：校验并关联经理。拒绝将沈越、唐敏或罗青设为陈卓经理，防止循环汇报。

## 空缺岗位补位

用岗位卡片比对缺口和候选人的能力证据，避免以人名替代岗位职责。

什么时候用：关键岗位离任后，需要记录内部补位安排。

什么时候别用：外部候选人简历筛选应放在招聘工作台。

状态：岗位待补位 / 候选资质不足 / 补位已确认 / 岗位已冻结

操作：确认岗位补位。只有苏芮或陶蕾持有本案要求的冷链审计证。

## 组织变更追溯

按时间保留组织版本，导出指定日期的部门归属供薪酬复核。

什么时候用：月末核账要还原某日人员所属的成本中心。

什么时候别用：历史快照不能用来证明当前员工的在职状态。

状态：历史版本可查 / 快照尚未生成 / 归属清单已导出 / 历史版本封存

操作：导出日期归属。仅导出11月01日至11月11日快照，拟定和撤销调令不改变历史归属。
