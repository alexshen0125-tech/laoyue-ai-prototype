# 复杂向导 · 交互模块

免费下载 · 双击就能打开 · 复制提示词直接给 AI 用。

> 积木盒 · 老岳AI编辑部 · 原型组 | 单文件 HTML，离线可用 | 2026-11-10

将长流程拆成可验证、可返回、可恢复的业务步骤。适合产品经理画原型、对齐研发与测试。共5种做法、22个可切换状态。所有数据为示例，不向外部发送。

## 做法与场景

| 做法 | 状态 | 什么时候用 | 什么时候别用 |
|---|---|---|---|
| 线性步骤与校验 | 填写 / 校验错误 / 确认 / 提交中 / 成功 / 失败 | 开户、发布等必须按顺序完成的流程 | 三个以内简单字段 |
| 条件分支 | 个人 / 企业 / 企业缺资料 / 确认 | 身份不同导致后续材料不同 | 不同分支几乎完全独立的业务 |
| 可选步骤与跳过 | 待设置 / 已跳过 / 已设置 | 通知等非核心配置可以稍后补 | 法定必填资料或付款确认 |
| 离开与恢复 | 编辑中 / 离开确认 / 发现草稿 / 已恢复 | 多分钟流程可能中途离开 | 密码等不宜保存在本机的内容 |
| 核对与定向修改 | 待核对 / 修改中 / 提交中 / 成功 / 失败 | 提交后修改成本高的申请 | 低风险的即时偏好设置 |

## 用法

1. 下载 `m-wizard.zip` 并解压，双击 `index.html`，无需安装和联网。
2. 左侧搜索或选择做法，右侧切换状态，也可直接填写、勾选和点击操作。
3. 顶部可换主题色、圆角和明暗，点击 AI 提示词按钮打开提示词面板。
4. 每种做法可一键复制当前状态 HTML，包含样式与变量。与标杆相同，复制的是外观片段，不含完整交互逻辑；需要交互时复制对应提示词。
5. 示例数据一般仅保存在当前页面内存，刷新重置；主题偏好和反馈邀请的“不再邀请”保存在本机，可在页面恢复。

## 交互与恢复规则

| 做法 | 操作与反馈 |
|---|---|
| 线性步骤与校验 | 下一步校验本步；回退保留输入；确认后提交，失败保留数据。 |
| 条件分支 | 切换身份保留已填内容，隐藏字段不校验，确认只汇总当前分支。 |
| 可选步骤与跳过 | 明确标注选填；跳过不阻塞；可返回补填。 |
| 离开与恢复 | 离开前询问；示例草稿仅保存在当前页面内存，刷新后清除。 |
| 核对与定向修改 | 按组核对，可定向修改；提交防重复，失败可重试。 |

处理中状态可直接查看，也可以从前一状态操作进入；模拟异步等待约0.65秒。切换做法状态会清理旧计时器。状态选择是演示入口，不代表真实业务后端。
