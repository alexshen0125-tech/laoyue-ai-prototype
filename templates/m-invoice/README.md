# 发票申请与流转

中文离线单文件。打开 index.html；顶部可下载本模块 zip。

## 购方抬头校验
企业与个人购方使用不同必填字段，企业税号保持完整而不混入地址栏。
什么时候用：订单付款后首次提交购方开票资料。
什么时候别用：境外税务主体不适用本演示的18位税号格式。
状态：企业抬头草稿 / 税号格式错误 / 个人购方 / 抬头已确认
交互：企业抬头至少4字、税号18位大写字母或数字；个人不提交隐藏的税号。

## 订单可开金额
从订单实付扣除已开票与退款金额，逐单展示剩余可开额度。
什么时候用：合并多笔订单开票前需要核对金额来源。
什么时候别用：未支付订单不应作为可开票收入。
状态：订单待选 / 超可开金额 / 明细已核对 / 无剩余额度
交互：选定订单后申请金额不能超过该单可开额度，负数或零不受理。

## 税率与价税分离
含税金额按税率拆分不含税价与税额，核对舍入后的价税合计。
什么时候用：票面明细需要展示税额而非只展示订单总价。
什么时候别用：商品税务分类码需按真实业务另行核定。
状态：含税金额录入 / 价税明细 / 税额舍入说明 / 开票申请已提交
交互：税额=含税总额减四舍五入至分的不含税价；当前仅模拟单一税率。

## 红字发票申请
选取原蓝票，明确部分退货还是整票撤销，红冲后保留原票关联。
什么时候用：开票后发生退货，需要调整原票金额。
什么时候别用：未开票订单退款无需发起红冲。
状态：原蓝票定位 / 红冲额度越界 / 红冲信息核对 / 红票已登记
交互：原票价税合计1280元；红冲金额须大于0且不超过未冲额度。

## 电子票交付回执
把票据生成与邮件交付分成两步，邮箱错误时仍可保留已生成票据。
什么时候用：电子票已生成，需要记录交付给谁及能否收取。
什么时候别用：邮件送达回执不等同于税务认证结果。
状态：电子票已生成 / 收票地址有误 / 交付失败待重试 / 收票回执已记录
交互：邮箱格式校验；失败只重试交付，不重复开票；票号固定用于追踪。
