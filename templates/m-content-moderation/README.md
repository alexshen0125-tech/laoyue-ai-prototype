# 内容审核

用证据、策略与复审责任支撑内容处置，保留申诉路径。

离线打开 index.html。示例数据均为虚构；除高级表单草稿外，业务修改仅在本次页面有效。

## 风险队列分流
五条投稿分别标出策略命中和待核证据。
适用：审核团队按风险程度领取任务。
不适用：模型评分不能直接作为封禁结论。
规则：高风险队列优先；同一投稿只保留一个领取人。
状态：投稿队列待领、投稿已被占用、审核任务可领、投稿任务已领

## 上下文证据核对
对照正文摘录与模型命中片段确认是否脱离语境。
适用：敏感词命中后需要人工看完整语境。
不适用：孤立关键词不足以证明违规。
规则：必须确认阅读上下文并写出至少八字证据。
状态：上下文待核读、审核证据不足、风险证据可记、上下文核对已记

## 内容处置裁定
在放行、限流和删除之间展示相应理由与影响。
适用：人工已核实内容需要作出处置。
不适用：删除是示例状态，不作用于真实投稿。
规则：删除需十字理由，放行记录误报依据。
状态：处置方式待选、处置理由缺失、审核裁定可交、内容裁定已记

## 申诉复审处理
将用户补充的出处与原裁定证据并排显示。
适用：创作者对删除结论提交申诉。
不适用：初审人不能担任本案复审人。
规则：初审林岚，复审需周遥且有出处说明。
状态：申诉材料待阅、申诉复核冲突、申诉证据可审、内容复审已记

## 抽样一致性复盘
五条已结案件展示双人判定差异并计算一致率。
适用：审核主管寻找策略歧义。
不适用：抽样一致率不能代表全量准确率。
规则：当前五案四案一致；差异案须记录策略澄清。
状态：审核样本待查、双审存在分歧、规则澄清可存、审核复盘已存
