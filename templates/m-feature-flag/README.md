# 功能开关与灰度

中文离线单文件，打开 index.html；顶部下载同名zip。保留主题、目录搜索、静态HTML与提示词复制。

## 账号灰度命中
为单个账号展示固定演示桶与曝光判断，不对展示用户数做假估算。
什么时候用：产品验证同一账号重复进入是否稳定。
什么时候别用：取模分桶不适合真实生产流量。
交互规则：整数账号末两位为桶0至99；开启比例0至100；桶小于比例命中。
状态：灰度比例草稿 / 灰度参数越界 / 账号命中灰度 / 账号留在旧版

## 白名单账号验证
将受邀内测账号与普通账号并列，白名单只作用于当前功能。
什么时候用：上线前为验收人员定向开通新版。
什么时候别用：不要把白名单误作后台管理员权限。
交互规则：名单初始1208、1361；必须输入正整数；可撤销新增账号。
状态：白名单待验证 / 账号未获邀请 / 内测账号已放行 / 新增邀请已撤销

## 环境隔离发布
测试、预发和生产使用独立开关值，生产发布需要再次输入环境名。
什么时候用：同一功能在多个环境以不同节奏上线。
什么时候别用：测试开关不能自动推送到生产。
交互规则：切换只编辑所选环境；生产必须输入production；其余环境直接保存。
状态：环境配置草稿 / 生产确认不匹配 / 预发开关已保存 / 生产开关已保存

## 紧急关闭与恢复门槛
停用卡区分新请求入口和已经执行的任务，恢复前要求留下验证结果。
什么时候用：故障期间快速切断智能推荐入口。
什么时候别用：关闭开关不会撤销已经下发的采购单。
交互规则：关闭原因至少6字；恢复需至少8字验证结论；重复关闭不增加事件。
状态：推荐功能运行 / 关闭原因缺失 / 新请求入口已关闭 / 验证后已恢复

## 到期开关治理
将开关负责人、到期日和残留代码引用排在同一张清理单中。
什么时候用：上线完成后清除临时灰度配置。
什么时候别用：仍有代码引用的开关不应直接删除。
交互规则：演示到期日11-10；基准11-11；引用数归零且有负责人才能归档。
状态：临时开关已到期 / 代码引用尚未移除 / 清理条件已满足 / 治理台账已归档
