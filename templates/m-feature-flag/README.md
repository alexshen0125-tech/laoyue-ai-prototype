# 功能开关与灰度

中文离线单文件原型。打开 index.html；顶部可下载同名zip。

- 百分比灰度：逐步扩大新能力曝光范围。输入范围 0–100%。
- 白名单验证：上线前给指定测试账号开放。输入范围 1–999999。
- 环境隔离：按环境设置独立开关。输入范围 1–3。
- 紧急关闭：故障时停止新请求进入能力。输入范围 100–599。
- 过期治理：为临时开关设置清理期限。输入范围 1–90天。

每种含5条独立业务记录及默认、待确认、失败与重试、成功、空态。选择记录→填写参数与说明→核对→预览→确认。修改使确认失效；失败保留输入；取消恢复，成功锁定防止重复。状态切换独立加载演示数据。
