# 工单 SLA 与超时升级

## 首次响应倒计时
将未响应工单按剩余分钟排序，人工回复后冻结首次响应结果。
什么时候用：客服接班核对未读客户请求时。
什么时候别用：机器人自动回执不能替代人工首次回复。
交互规则：期限1至1440整数分钟；演示已等待18分钟，回复保存实际耗时。
状态：响应队列 / 响应期限非法 / 首响已超时 / 人工首响已记录

## 按严重级别计算解决期限
支付中断和普通咨询分配不同解决窗口，截止时间从受理时刻计算。
什么时候用：班长按影响范围分派故障优先级。
什么时候别用：不要靠调低级别消除已发生的超时。
交互规则：11月11日09:00受理；P1为60分、P2为240分、P3为1440分；当前11:00。
状态：故障定级 / 紧急单逾期 / 常规单在时限内 / 解决结论归档

## 超时升级链
展示一线客服到值班主管的单向升级链，升级后保留原负责人。
什么时候用：高风险工单超过当前处理组承诺时长。
什么时候别用：没有值班主管时应先补齐排班。
交互规则：等待65分钟；阈值1至1440；只有到期且选好主管可升级一次。
状态：升级链待判定 / 未到升级节点 / 升级接收人缺失 / 主管已接管

## 等待材料停表
以计时分段展示等待客户补证的暂停区间，恢复时扣除暂停耗时。
什么时候用：退款凭证确实需要客户补交。
什么时候别用：内部转派和员工休假不属于客户等待。
交互规则：只允许等待客户暂停；固定暂停15分钟；有效处理时间为60减15。
状态：处理计时中 / 停表原因不适用 / 等待客户已停表 / 补证恢复计时

## 临期提醒窗口
把未来截止时间放进提醒窗口，去除已经超时和已经提醒的工单。
什么时候用：班长准备处理即将到期的队列。
什么时候别用：已超时事项走升级链而非临期提醒。
交互规则：提前量1至60分钟；剩余8分钟命中，已超时项排除；同轮只记一次。
状态：提醒窗口配置 / 提醒窗口越界 / 临期对象已选出 / 内部提醒已登记
