# AI 客服转人工

离线单文件交互原型。打开 index.html 使用；下载包包含页面及核验记录。标准外壳沿用 _kit。

## 转接条件判断
比较意图置信度与投诉信号，明确转人工原因。
什么时候用：AI遇到赔付争议或低把握回答。
什么时候别用：高风险诉求不得只靠置信度自动答复。
业务状态：会话风险待判 / 转接置信度无效 / 会话可由AI继续 / 会话需要人工介入
交互规则：置信度0至1；低于0.7或赔付争议须转人工。

## 交接摘要核对
把用户诉求、已做动作和未决问题装入交接卡。
什么时候用：人工接单前需要快速了解上下文。
什么时候别用：未经授权的敏感信息不应写入摘要。
业务状态：交接摘要待写 / 摘要包含敏感信息 / 交接卡可送出 / 会话摘要已交接
交互规则：摘要至少12字，禁止包含手机号样本13800138000。

## 人工队列路由
按语言与技能匹配接待队列并显示预计等待。
什么时候用：用户已确认需要人工处理。
什么时候别用：非工作时段需另设留言承接方案。
业务状态：接待技能待匹配 / 队列技能不匹配 / 人工队列可接入 / 会话已进入队列
交互规则：赔付专席可受理争议，普通售前不具赔付权限。

## 客服接管互斥
在接管前再次核对会话归属，避免多人同时回复。
什么时候用：两位客服同时查看同一排队会话。
什么时候别用：接管演示不连接真实在线坐席。
业务状态：会话接管待核 / 其他坐席已接管 / 当前坐席可领取 / 人工接管已生效
交互规则：会话已由陈宁领取时禁止林岚再次接管。

## 处置结论与回流
区分已解决和继续跟进，避免把未结诉求回交AI。
什么时候用：客服准备结束赔付咨询会话。
什么时候别用：用户仍有异议时不能自动关闭。
业务状态：处置结论待填 / 结论证据不足 / 会话仍需人工跟进 / 人工处置已归档
交互规则：结论至少12字；仅用户已确认解决允许归档。
