# 招聘流程

离线单文件交互原型。打开 index.html 使用；下载包包含页面及核验记录。标准外壳沿用 _kit。

## 岗位编制申请
对照季度编制余额，避免无预算启动招聘。
什么时候用：部门提出新增岗位时。
什么时候别用：外包采购需另走服务商流程。
业务状态：岗位人数待填 / 超出招聘编制 / 岗位预算可承接 / 招聘需求已立项
交互规则：申请人数为1至3整数，当前剩余2席。

## 候选人初筛
以技能证据筛选进入技术面的候选人。
什么时候用：简历收集完成后安排首轮筛选。
什么时候别用：不得以年龄或性别代替岗位能力。
业务状态：简历证据待核 / 技能证据待补 / 候选人可约面 / 技术面邀请已暂存
交互规则：选择候选人查看证据，缺少SQL项目记录需补充。

## 面试官排期
并排比较面试官日程与候选人意向。
什么时候用：技术面需要两位面试官共同参加。
什么时候别用：异步作业评阅无需占用面试时段。
业务状态：面试时间待定 / 面试官日程冲突 / 面试时段可用 / 面试安排已锁定
交互规则：11月13日14点面试官冲突，15点可用。

## 面试评价归档
分开记录能力评分与可追溯的面试观察。
什么时候用：面试结束需要评审录用建议。
什么时候别用：主观好恶不能作为评价证据。
业务状态：面试记录待写 / 评价证据不充分 / 建议进入录用评审 / 暂缓录用已记录
交互规则：评分1至5，观察至少12字；低于3分不推荐。

## 录用条件确认
将期望薪资与岗位薪酬区间对齐后生成录用草案。
什么时候用：录用评审通过准备沟通条件。
什么时候别用：正式法律文本需经企业授权签发。
业务状态：录用条件待核 / 薪资超出授权 / 录用草案可生成 / 录用草案已暂存
交互规则：月薪范围18000至26000元，超上限走特批。
