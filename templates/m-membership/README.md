# 会员等级与权益

中文离线单文件，打开 index.html；顶部下载同名zip。保留主题、目录搜索、静态HTML与提示词复制。

## 成长值与等级试算
用累计成长值展示升级阶梯，输入新增值后计算下一等级差额。
什么时候用：客服向会员解释还差多少成长值升级。
什么时候别用：保级到期日不通过增加试算值自动续期。
交互规则：初始860；银卡500、金卡1000、黑金5000；新增0至10000整数。
状态：成长试算草稿 / 成长值输入非法 / 下一等级差额已算 / 成长试算已保存

## 月度配送券领取
在权益卡上明确会员等级、发放周期和本月领取记录。
什么时候用：金卡会员领取每月一次配送券。
什么时候别用：已领取的券不能通过刷新状态再次发放。
交互规则：普通会员不具资格；金卡每月一次；领取后重复操作显示已领取。
状态：月度权益可领取 / 会员等级不够 / 本月权益已领取 / 重复领取已阻止

## 积分与礼品库存双检
兑换同时展示积分成本和礼品现货，成功后扣除余额并锁定当前请求。
什么时候用：会员使用积分兑换实物权益。
什么时候别用：成长值不是可以消费的积分余额。
交互规则：初始860分；礼盒500分有货、餐券1000分有货、雨伞300分缺货。
状态：会员礼品货架 / 兑换积分不足 / 礼品库存为零 / 会员礼品已兑换

## 保级任务证据提交
黑金保级按本周期成长值判断，任务凭证先送审再考虑计入。
什么时候用：到期前告知会员本周期缺口及可做任务。
什么时候别用：提交任务凭证不能视为任务审核通过。
交互规则：周期目标3000、已计2450、差550；任务订单号必填、说明至少8字。
状态：黑金保级待完成 / 任务凭证不完整 / 保级任务待审核 / 保级任务已撤回

## 权益使用台账
分别追踪已领、已用和已过期权益，按状态筛选不改变账户余额。
什么时候用：会员询问配送券为何不能再次使用。
什么时候别用：权益台账不是积分财务流水。
交互规则：五条权益状态独立；筛选可得空结果；导出当前可见记录。
状态：全部权益记录 / 权益状态已筛选 / 所选状态无记录 / 权益台账已下载
