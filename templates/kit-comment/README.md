# 评论与讨论组件库

免费下载 · 双击就能打开 · 复制提示词直接给 AI 用。

协作讨论台 · 原创示例。讨论内容只停留在当前演示，不会通知其他人。

## 用处

供评审协作的产品经理与开发人员核对讨论路径；单个控件负责意见流，业务模块管理审计和通知。

## 用法

1. 打开解压目录里的 index.html，按讨论任务找到对应编辑器。
2. 用顶部主题设置比较评论区深浅效果，再查看发送、审核和冻结状态。
3. 一键复制 HTML 保存当前讨论界面；发布、提及等事件依赖 render/mount 及其辅助函数。
4. 组件提示词包含讨论规则，顶部三个场景支持填写评审业务变量。
5. 免费下载链接使用本地 kit-comment.zip 文件。

## AI 提示词

### 建立讨论控件集

创建评论输入、人员提及、表情附件、嵌套回复、举报折叠五组控件。评论正文有字数限制与空白校验，发送后冻结防重；举报只进入审核队列。每组列出业务状态和键盘操作，演示小中大控件与焦点外观。用集中CSS变量组织主题，交付可离线打开且逐项复制的HTML及说明表。

### 拼装方案评审区

用附件中的讨论控件搭建{{业务名称}}的{{页面类型}}。围绕评论正文组织发布、定向回复和补充附件，回复深度最多两层，超出转平铺。将审核排队、被折叠与发送失败分别表达；只模拟本地提交，不向任何成员发送通知。提供自包含页面、上下文保留策略和正常及异常状态示例。

### 扩展审核互动

为{{组件名称}}设计{{状态清单}}，重点解释评论正文何时可编辑、修改后是否重新审核、举报撤回的限制。按当前画廊接口增加section，给出具体适用与禁用情境、输入校验、焦点返回和三种尺寸；交付离线HTML及审核流转表，不捏造后台审核结果。
