# 对账差异处理

打开 index.html 即可离线使用，支持深浅主题、做法搜索、状态快照、提示词复制、HTML复制与模块ZIP下载。

## 双边账单匹配

按流水号连接渠道到账与订单实收，未匹配项保留在两侧。

什么时候用：支付渠道回传账单后，财务需要定位漏单与金额不符。

什么时候别用：银行结息流水应进入资金账而非订单匹配。

状态：渠道账待匹配 / 账单日期未覆盖 / 匹配结果已生成 / 账单格式不符

操作：运行流水匹配。仅11月10日账单可匹配，返回3笔一致、1笔10元差额和1笔72.80元单边款。

## 差异归因与挂账

把少到账拆成手续费、短款或未达款，挂账科目随原因联动。

什么时候用：匹配发现金额差异，需要安排下一步财务处理。

什么时候别用：已结清流水不能再次挂账产生重复资产。

状态：短款待归因 / 凭证依据不足 / 挂账已登记 / 差异已转未达

操作：登记差异挂账。凭证依据至少6字符，10元差额随选定科目进入暂挂记录。

## 未达款账龄

以结算承诺日计算逾期，先关注超过三个工作日的未达款。

什么时候用：资金尚未到账，需要按账龄安排渠道追索。

什么时候别用：明确坏账需走核销审批，不能一直留在未达池。

状态：未达款在途 / 未到追索窗口 / 追索任务已建 / 到账凭证已回传

操作：建立追索任务。尚未到11月12日承诺窗口的YD-1112不生成逾期追索。

## 调账分录预览

在入账前列出借贷方向，并拦截不平衡的调整分录。

什么时候用：渠道补款或差额确认后，需要把暂挂科目转回银行存款。

什么时候别用：未获确认的争议款不应直接转为已到账。

状态：调账分录草稿 / 借贷不平衡 / 分录已记入模拟账 / 凭证期间锁定

操作：校验并登记分录。借贷金额必须各10元，不能超出当前暂挂余额。

## 关账检查与结案

将开放差异、分录和复核责任串成关账门槛，避免带着悬账结案。

什么时候用：日对账结束，出具可复核的结案清单。

什么时候别用：有未解决短款时不得以强制关账掩盖差异。

状态：关账检查待执行 / 仍有开放差异 / 日账已结案 / 结案后申请重开

操作：执行关账检查。单边款需补关联SO483，且复核人必须为彭蕊才可结案。
