# 销售漏斗与商机

离线单文件交互原型。打开 index.html 使用；下载包包含页面及核验记录。标准外壳沿用 _kit。

## 线索资质判定
把预算与采购时点作为是否建商机的依据。
什么时候用：销售收到企业采购咨询准备判断优先级。
什么时候别用：资质判定不应替代客户访谈。
业务状态：线索资质待核 / 预算信息不合法 / 线索暂入培育池 / 客户商机已建立
交互规则：预算至少5万元，预计采购周期不超过90天。

## 商机阶段推进
为方案转报价设置决策人确认这一推进证据。
什么时候用：销售完成方案沟通准备出具商务报价。
什么时候别用：仅发送资料不能视为客户认可方案。
业务状态：方案阶段待核 / 决策人信息缺失 / 报价阶段可推进 / 商机已进入报价
交互规则：推进报价必须记录客户决策人。

## 加权收入预测
按五笔商机概率计算本月可预测收入。
什么时候用：销售主管编制月度收入预测。
什么时候别用：加权金额不能当作已确认收入。
业务状态：成交概率待估 / 概率超出范围 / 加权收入已测算 / 收入预测已锁版
交互规则：目标商机金额20万元，成交概率0至100。

## 停滞商机跟进
用上次联系日期识别风险并制定下一步动作。
什么时候用：管道会议需要处理两周未推进的商机。
什么时候别用：客户明确拒绝后应尊重沟通边界。
业务状态：停滞商机待跟进 / 跟进计划不完整 / 挽回计划可登记 / 商机跟进已排期
交互规则：下一步计划至少10字，跟进日不得早于2026-11-11。

## 赢单输单归档
以订单号或输单原因结束机会并保留复盘依据。
什么时候用：客户已经明确采购结果。
什么时候别用：口头意向不可直接计入赢单收入。
业务状态：成交结果待定 / 赢单凭证缺失 / 商机赢单已归档 / 商机输单已复盘
交互规则：赢单需SO加6位数字；输单原因至少8字。
