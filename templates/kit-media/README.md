# 媒体交互组件库

以离线矢量样张演示选图、播放控制、音频波形及图像编辑。

离线打开 index.html。示例数据均为虚构；除高级表单草稿外，业务修改仅在本次页面有效。

## 图片画廊与大图
五张场景样张有独立标题和选择反馈，可打开大图并关闭。
适用：资料审核需要逐张查看图片。
不适用：像素质量评估不能使用矢量样张。
规则：选择缩略图改变大图；弹层Escape关闭并归还焦点。
状态：仓库主图浏览、装卸细节选中、安全通道选中、图片大图展开、夜间场景选中、打包工位选中、图片说明隐藏、图库只读检查

## 视频时间轴控制
用本地程序绘制训练片段并提供播放暂停和定位。
适用：培训视频播放器需要离线控件样例。
不适用：该图形演示不代表视频编码兼容性。
规则：总长90秒；播放推进时间，尾帧停止；静音与速度可切换。
状态：训练视频待播、训练视频暂停、训练片段定位、训练视频结束、视频静音预览、二倍速预览、视频时长待读、播放器控件锁定

## 音频波形与选段
固定波形对应12秒离线合成提示音，选择起止区间后试听。
适用：客服质检需要反复听取一段录音。
不适用：合成音不能用作语音内容识别。
规则：起点必须小于终点；支持停止播放；音频由Web Audio本地生成。
状态：音频选段待设、音频区间反向、音频区间可听、音频试听结束、前段波形聚焦、后段波形聚焦、音频输出静音、音频能力受限

## 图片裁剪边界
在样张上移动裁剪框并查看输出比例。
适用：素材需要统一封面构图。
不适用：本演示不导出真实照片像素。
规则：横坐标0至60，裁剪宽度40%；确认后冻结边界。
状态：裁剪边界待调、裁剪坐标越界、裁剪区域可用、裁剪框已确认、裁剪靠左构图、裁剪居中构图、裁剪靠右构图、裁剪边界锁定

## 图片缺陷标注
把缺陷备注与图中坐标绑定，允许清除重标。
适用：现场验收需要指出具体破损位置。
不适用：标注坐标不能替代实测尺寸。
规则：点击样张定位；描述至少六字；保留坐标与描述配对。
状态：缺陷位置待点、缺陷说明过短、缺陷标注可存、缺陷标注已存、上沿缺陷预览、底角缺陷预览、标注只读核对、标注记录已清
