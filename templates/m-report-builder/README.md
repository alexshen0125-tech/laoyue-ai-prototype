# 报表设计与导出

中文离线单文件，打开 index.html；顶部下载同名zip。保留主题、目录搜索、静态HTML与提示词复制。

## 指标与聚合口径
金额求和和订单去重分别显示计算口径，避免把行数当成交单量。
什么时候用：经营看板新增销售额或订单指标。
什么时候别用：跨币种收入应先统一换算口径。
交互规则：收入只能求和、订单只能去重；源数据5条含重复订单，去重为4单。
状态：指标口径草稿 / 聚合方式不匹配 / 指标试算完成 / 指标口径已保存

## 维度分组与小计
按门店或渠道重新组合同一份收入明细，每组小计可追溯原记录。
什么时候用：需要从门店汇总切到销售渠道观察。
什么时候别用：维度分组不会改变原始交易金额。
交互规则：五条明细总额734；门店4组、渠道2组；小计之和必须等于734。
状态：分组维度待选 / 按门店汇总 / 按渠道汇总 / 分组口径已锁定

## 图表适配与预览
分类金额采用柱图，日期序列可用折线；不支持组合时给出替代选择。
什么时候用：报表搭建时决定怎样展示聚合数据。
什么时候别用：不要对无时间顺序的门店名称连折线。
交互规则：门店配折线被阻断；柱图展示4店收入；日期可输出折线SVG。
状态：图表布局草稿 / 维度图形不适配 / 图表预览已生成 / 图表配置已采用

## 日期与空结果
预览筛选后的交易明细，结束日早于开始日时不执行查询。
什么时候用：运营排查某段日期的收入变动。
什么时候别用：演示数据只覆盖11月8日至11月11日。
交互规则：日期ISO格式；范围包含11-11命中5条，否则空；逆序范围拒绝。
状态：日期筛选草稿 / 日期范围无效 / 收入明细已筛出 / 期间没有交易

## 标题与CSV快照
将报表标题和门店小计一起固化到CSV文件，下载内容和预览使用同份数据。
什么时候用：报表负责人准备提交线下经营会议。
什么时候别用：本地快照不提供定时订阅或实时刷新。
交互规则：标题至少4字；先预览再下载；CSV包含4门店和口径说明。
状态：报表导出草稿 / 报表标题不完整 / CSV内容已预览 / 报表快照已下载
