# 问卷设计与投放

中文离线单文件。打开 index.html；顶部可下载本模块 zip。

## 题型编辑
满意度量表、购买渠道单选与开放建议使用不同的答题控件。
什么时候用：研究目标已明确，需要编排可回答的题目。
什么时候别用：已有成熟量表时不要随意改动原题含义。
状态：题目草稿 / 题干缺失 / 答题预览 / 题目已锁定
交互：选择题型后预览控件，题干不能为空；发布前锁定题目版本。

## 逻辑跳转
未购买用户跳过售后评分，进入未购原因题。
什么时候用：问卷包含互斥人群与不适用的问题。
什么时候别用：纯线性三题问卷不必增加跳转负担。
状态：分支配置 / 回跳被阻断 / 购买路线 / 未购路线
交互：仅允许跳往后续题；测试购买与未购两条路线。

## 投放渠道配额
门店二维码、会员短信与公众号各自分配回收目标。
什么时候用：需要对比不同触点的用户意见。
什么时候别用：渠道来源无法识别时不可声称分组代表性。
状态：渠道待分配 / 配额不平衡 / 渠道已就绪 / 投放已暂停
交互：三渠道配额总和必须等于300，生成的是本地渠道编号。

## 答卷质检
将作答时长、重复设备与缺失题目分开审核，保留剔除原因。
什么时候用：回收后检查低质量答卷对结论的影响。
什么时候别用：不得只因观点负面就剔除答卷。
状态：答卷待审 / 异常待核实 / 剔除已确认 / 全部保留
交互：低于10秒或重复设备标记待剔除；确认后展示有效样本数。

## 匿名汇总
样本不足的门店分组隐藏明细，只展示达到阈值的聚合结果。
什么时候用：员工或会员调查需要保护小样本人群。
什么时候别用：需要联系受访者的售后工单不适合匿名统计。
状态：匿名门槛设置 / 小组数据隐藏 / 汇总可分享 / 回收已结束
交互：匿名门槛至少5人；杭州组4人隐藏；关闭回收后固定汇总快照。
