## 用处

面向产品经理、设计师和前端开发者，帮助比较组件状态、说明交互规范和快速拼原型。组件是可组合的元素，模块组织业务任务，页面模板承载完整页面。本库可复制进模块，也可附给 AI 生成业务页面。

## 用法

1. 解压，双击 index.html；所有样式、脚本、SVG 已内联，无须服务器或网络。
2. 左侧搜索组件，每项上方切状态；顶部更换主题色、圆角、明暗。
3. 点每项「一键复制 HTML」粘入 HTML，片段附带 CSS 变量、样式和使用到的图标。默认复制当前状态的静态外观；完整交互请复用 index.html 对应 section 的 mount 和依赖函数，或用组件提示词让 AI 补齐。
4. 点每项「一键复制提示词」，获取用途、限制、状态和交互说明。
5. 顶部「AI 提示词」面板可填变量并复制，顶部「免费下载」下载同目录 kit-nav.zip。

导航只切换本地示例内容，不跳转外部页面。Tab 支持方向键、Home、End；分页和步骤具有边界；锚点滚动发生在演示区。

## 页面上的 AI 提示词

提供 3 条可直接复制的提示词：

- **从零生成这套组件库**：建立同类画廊，明确组件清单、状态、尺寸、离线和变量要求。
- **用这套组件拼出整页**：填写 `{{页面类型}}`、`{{业务名称}}`，附上 index.html，要求正常、空、加载、出错状态与交互说明表。
- **给组件库加一个组件**：填写 `{{组件名称}}`、`{{状态清单}}`，附上 index.html，沿用 section、主题和复制功能。
