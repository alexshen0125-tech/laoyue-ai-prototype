# 地址与配送范围组件库

免费下载 · 双击就能打开 · 复制提示词直接给 AI 用。

履约位置台 · 原创示例。坐标为SVG演示平面，不代表真实道路或配送承诺。

## 用处

供履约产品与交互设计师比较选址方案；位置控件只表达覆盖关系，业务页面负责真实地址服务。

## 用法

1. 从压缩包解出 index.html 后直接打开，按位置任务浏览四组控件。
2. 切换顶部主题并调整圆角，用三种画布尺寸比较地址与圈域表达。
3. 复制 HTML 可取得内联SVG和当前控件样式；点位移动与距离计算需移植 render/mount。
4. 复制专属提示词可保留比例和边界约束，顶部面板适合填写履约页面变量。
5. 本地下载按钮对应 kit-map-location.zip。

## AI 提示词

### 绘制离线位置画廊

以纯SVG绘制地址选择、地图点位、范围圈选和距离配送提示。配送半径用演示网格计算，明确直线距离与真实路网时间不同。地址列表至少五个不同站点；点位可点击与键盘移动；范围滑块实时更新圈形。用CSS变量切换主题并提供各业务状态、交互外观和尺寸，输出不调用地图服务的单文件HTML。

### 拼接履约地址页

围绕{{业务名称}}的{{页面类型}}组合地址列表、标记点和配送半径，显示选中收货站、距离及是否覆盖。定位被拒时可手动选择；边界外说明不能承诺配送，边界内仍标记为演示。不得捏造真实地理坐标或到达时间，交付纯SVG离线页面、正常和故障路径以及比例换算说明。

### 增加圈域规则

给{{组件名称}}补充{{状态清单}}，描述配送半径与禁送区域发生交叠时如何提示、修改和撤销。复用位置画廊的section接口与变量，补上具体use/avoid/spec、小中大尺寸和键盘路径。提供完整内联SVG的HTML与边界判定表，明确所有距离只依据示意坐标。
