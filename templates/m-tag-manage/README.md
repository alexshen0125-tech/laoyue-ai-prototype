中文离线单文件，打开 index.html；顶部下载同名zip。保留主题、目录搜索、静态HTML与提示词复制。

## 标签词典与重名检查
新标签先校验名称和分组，再进入业务词典，避免同义标签随意扩散。
什么时候用：客户运营要补充稳定的风险分类。
什么时候别用：一次性备注不适合占用长期标签词典。
交互规则：名称2至12字；去首尾空格后检查重名；已有冷链重点等五标签。
状态：词典标签草稿 / 标签名称不可用 / 标签词条可创建 / 新标签已加入词典

## 标签分组搬移
将风险标签从经营组迁往履约组，预览新路径并保留标签本身的引用。
什么时候用：标签目录变大需要调整分类结构。
什么时候别用：搬组不应改变客户已经绑定的标签ID。
交互规则：账期风险初在客户经营；不同分组才能移动；保存后引用数量46不变。
状态：标签分组待调整 / 来源目标相同 / 新分组路径预览 / 标签分组已变更

## 客户批量标记
用明确的客户名单预览新增标签，已经拥有该标签的客户跳过而非重复绑定。
什么时候用：一次给近期复购客户加运营标签。
什么时候别用：批量标记不能覆盖客户原有其他标签。
交互规则：固定5客户；高频采购已有2人；新增3人；确认后当前批次锁定。
状态：标记批次草稿 / 五客户范围预览 / 三客户新增完成 / 批次结果已导出

## 重复标签合并映射
将低频旧词并入规范标签，合并前展示引用去重数量和旧ID映射。
什么时候用：词典里同时出现高频客户与高频采购。
什么时候别用：不同含义的风险标签不应为了减少数量而合并。
交互规则：源标签不能等于目标；旧标签34引用、目标46、重叠8，合并后72。
状态：合并映射草稿 / 源目标标签相同 / 引用去重已预览 / 旧标签映射已建立

## 引用保护与废弃
先停用存在引用的标签，只有引用归零才允许删除词条。
什么时候用：清理过时的门店阶段标签。
什么时候别用：历史关联尚在时不能抹去标签定义。
交互规则：引用数非负整数；有引用仅允许停用；零引用可删除；操作保留审计号。
状态：标签清理检查 / 引用存在禁止删除 / 标签已停用 / 零引用词条已删除
