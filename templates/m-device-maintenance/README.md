# 设备维保

以设备周期、工单、备件与验收结果形成维护闭环。

离线打开 index.html。示例数据均为虚构；除高级表单草稿外，业务修改仅在本次页面有效。

## 保养周期计划
五台设备按运行小时与保养阈值标出近期任务。
适用：设备主管制定本周预防性维护。
不适用：安全停机设备不得等到计划日期再修。
规则：累计1000小时触发维护；计划须指定工程师。
状态：设备周期待核、设备维护逾期、保养任务可排、维保计划已排

## 故障分级派修
根据振动等级与停机状态识别紧急工单。
适用：冷机巡检发现异常噪声。
不适用：界面示例不能代替安全停机操作。
规则：振动超过7毫米每秒转紧急，读数须为非负数。
状态：故障读数待录、设备振动告警、派修等级已判、维修工单已派

## 备件领用核对
对照五种备件库存与需求，禁止超库存领用。
适用：维修人员准备替换冷机皮带。
不适用：危险耗材需另走专用许可。
规则：皮带库存3件，领用须为1至3整数。
状态：备件领用待填、备件库存不足、维修备件可领、备件出库已记

## 维修工时记录
把实际维修时长和具体动作记录到设备工单。
适用：维修结束需要核算维护成本。
不适用：停机等待时长不计为动手维修工时。
规则：工时0.5至16小时，维修说明至少十二字。
状态：维修工时待记、维修记录缺项、维修日志可交、设备维修已记

## 试运行验收
以回测温度与复核人签认决定是否恢复设备。
适用：维修完成需要确认运行稳定。
不适用：试运行通过不等于长期无故障。
规则：冷机出风温度2至6度；必须由独立验收员周遥签认。
状态：设备回测待录、试运行未达标、恢复运行可签、设备维保已结
