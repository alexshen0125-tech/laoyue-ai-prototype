# 合同签署流程

中文离线单文件。打开 index.html；顶部可下载本模块 zip。

## 签署方顺序
采购合同先由采购负责人确认，再流转到供货方与用印人。
什么时候用：多主体合同需要约束谁先签、谁后签时。
什么时候别用：单方声明无需建立多人串行邀请。
状态：顺序草稿 / 首位待签 / 签署方拒签 / 全员签毕
交互：调整前两位顺序并预览邀请链；拒签停止后续流转。

## 签章位置
把公司章放在合同末页，骑缝章独立于落款章配置。
什么时候用：需要核对PDF页码与签章锚点的用印申请。
什么时候别用：扫描件缺页时先补齐文件再定位。
状态：末页落款 / 印章越界 / 位置已锁定 / 文件版本变化
交互：页码限定1至8，坐标按百分比限制在15至85；定位后才可锁定。

## 签署意愿认证
签署前对照签约主体，选择短信或人脸认证的演示路径。
什么时候用：邀请链接已打开且准备确认签署意愿。
什么时候别用：离线展示的验证码不可用作真实身份凭证。
状态：身份待核对 / 验证码错误 / 意愿已认证 / 本方已签署
交互：固定演示码381642；错误不认证；认证后仍需明确点击签署。

## 邀请期限与催签
把待签方的剩余时长与可催签窗口放在同一时间线上。
什么时候用：合同临近截止且仍有签约人未完成。
什么时候别用：已撤回合同不得再次发送旧邀请。
状态：邀请有效 / 即将到期 / 已过有效期 / 催签已记录
交互：有效期按2026-11-11计算；到期禁止催签；同轮只生成一次提醒。

## 撤回与证据归档
未完成合同记录撤回原因，完成合同保留签署时间和文件摘要。
什么时候用：纠正发错版本的邀请或下载已签证据清单。
什么时候别用：争议保全期间不能按普通归档期限删除材料。
状态：待处理邀请 / 撤回原因不足 / 邀请已撤回 / 证据已归档
交互：撤回原因至少6字；已签完仅允许归档；归档列出文件与认证证据。
