# 价格与促销规则

中文离线单文件，打开 index.html；顶部下载同名zip。保留主题、目录搜索、静态HTML与提示词复制。

## 按商品折扣定价
逐商品显示原价、优惠和实付，让运营检查大额规格是否折价过深。
什么时候用：同系列套餐使用统一折数促销。
什么时候别用：折后价不自动与会员折扣继续相乘。
交互规则：折数0.1至10；每商品四舍五入至分；单独展示优惠额。
状态：实付折数草稿 / 折数范围非法 / 五商品折后价预览 / 折扣方案已保存

## 满额立减试单
先看商品金额是否达到门槛，再计算一次性立减，不按倍数反复扣减。
什么时候用：营销配置满200减20这类订单活动。
什么时候别用：运费和储值充值不参与本演示门槛。
交互规则：门槛正数、减免大于0且不超门槛；试单商品金额非负。
状态：满减参数草稿 / 满减关系不成立 / 订单尚未达门槛 / 满减实付已算出

## 会员专享资格与价格
会员身份未满足时保留普通售价，金卡命中后才显示专享实付。
什么时候用：结账前验证会员价的适用人群。
什么时候别用：专享价不能作为所有访客可用的售价。
交互规则：原价259；仅金卡黑金享9折；专享价233.10；重复计算不扣余额。
状态：专享资格待核对 / 普通会员不适用 / 金卡价格已命中 / 专享价已采用

## 优惠互斥择优
并列比较活动券与会员价，只选一个更优惠的结果，不连乘或重复减免。
什么时候用：同一订单同时满足两种互斥优惠。
什么时候别用：可叠加活动需要单独的规则模型。
交互规则：原价259；会员价233.10；活动券输入0至259；择低实付，保留未选原因。
状态：互斥优惠待比较 / 优惠券金额越界 / 最优方案已选出 / 互斥选择已确认

## 补贴预算原子试扣
从总预算扣除已用额得到余额，预览足额后才占用本次补贴。
什么时候用：活动开始前判断还能承担多少新优惠。
什么时候别用：试扣账本不是支付渠道的真实资金冻结。
交互规则：预算2000、已用1860、余额140；申请正数且最多两位小数；一次只占用一次。
状态：活动预算概览 / 补贴申请超过余额 / 补贴额度可占用 / 本次补贴已占用
