# AI 回答反馈与闭环

中文离线单文件，打开 index.html；顶部下载同名zip。保留主题、目录搜索、静态HTML与提示词复制。

## 回答质量分项评价
评价针对当前回答版本，选择问题类别后补充具体影响。
什么时候用：用户认为回答有误但尚未掌握政策依据。
什么时候别用：不喜欢语气不等同于事实错误。
交互规则：选择分类且意见至少8字；每个回答版本只提交一次评价。
状态：回答评价草稿 / 评价缺少具体说明 / 评价内容待核对 / 质量反馈已提交

## 事实修订与证据对照
并排保留错误表述和政策原文，建议修订经过核对后进入人工队列。
什么时候用：已找到免邮门槛相关的正式政策条目。
什么时候别用：引用不明的口头说法不能直接覆盖政策。
交互规则：来源非空、政策原文至少12字、修订至少8字；提交不代表已上线。
状态：事实修订草稿 / 修订证据不完整 / 修订差异已核对 / 事实修订待人工审

## 引用版本核验
查看引用所指文档版本与当前生效版本，过期时要求换成有效依据。
什么时候用：回答链接能打开但内容来自旧政策。
什么时候别用：可访问链接不代表该政策仍然生效。
交互规则：引用v3已过期、v4生效；确认替换保留旧引用审计记录。
状态：引用待核验 / 引用版本已过期 / 当前政策已定位 / 引用替换已登记

## 隐私反馈脱敏预览
在提交反馈前遮罩回答里的电话与邮箱，原文仅用于本地对照。
什么时候用：用户发现回答泄露联系人资料。
什么时候别用：脱敏预览不能认定服务端历史日志已被清理。
交互规则：固定电话和邮箱替换为遮罩；分享必须先核对脱敏稿；不上传原文。
状态：隐私问题原文 / 脱敏文本待确认 / 隐私反馈已提交 / 本地原文已清除

## 反馈编号与处理进展
根据反馈编号返回各阶段处理记录，未发布修订时不承诺问题已解决。
什么时候用：提交者回访事实修订是否进入发布。
什么时候别用：审核通过与知识版本上线应分别确认。
交互规则：支持五个固定反馈编号；未知编号显示未找到；已发布记录带知识版本。
状态：反馈进度查询 / 反馈编号未找到 / 核验流程进行中 / 修订版本已发布
