# 库存风险预警

中文离线单文件。打开 index.html；顶部可下载本模块 zip。

## 安全库存线
区分账面数量与锁单数量，以可售库存判断是否跌破安全线。
什么时候用：高周转商品需要及时识别可用量不足。
什么时候别用：不应把已锁定待发货数量继续计入可售。
状态：库存基线 / 安全线预览 / 低库存已标记 / 安全线越界
交互：可售等于账面减锁单；安全线1至500件；缺口逐SKU计算。

## 可售天数预测
把日均销量和可售量相除，零销量单独标注而不展示无穷天数。
什么时候用：采购需要按预计断货先后安排补货。
什么时候别用：新品缺乏稳定销量时不宜把结果当作确定需求。
状态：常态销售预测 / 促销加速消耗 / 无销量无法预测 / 三日内断货风险
交互：预测按近7日均销，促销倍率0.5至4；低于3天标为紧急。

## 补货建议单
按采购提前期加缓冲天数计算目标量，再扣除可售和在途。
什么时候用：有稳定供货周期的补货审核。
什么时候别用：建议量未经过预算审批前不能直接下采购单。
状态：补货参数 / 建议数量核对 / 在途足够无需补货 / 采购草稿已生成
交互：提前期1至30天、缓冲0至14天；建议量向上取整且不小于0。

## 风险批次隔离
将温控异常批次从可销售数量中隔离，保留原因和复检依据。
什么时候用：质检发现具体批次存在潜在质量问题。
什么时候别用：商品全量下架与批次隔离的影响范围不同。
状态：批次待判断 / 隔离数量不合法 / 批次已隔离 / 复检后已释放
交互：隔离不能超过批次数量；未填复检结论不能释放；隔离记录不真实扣库存。

## 风险通知冷却
同一SKU和仓库的同类风险在冷却窗口内合并，避免反复提醒采购。
什么时候用：定时扫描会多次发现同一风险。
什么时候别用：风险升级时不得被普通冷却策略静默抑制。
状态：提醒策略 / 同类提醒被抑制 / 升级提醒放行 / 通知草稿已生成
交互：冷却时长1至72小时；上次提醒距今2小时；严重升级单独放行。
