# 移动端审批

中文离线单文件，打开 index.html；顶部下载同名zip。保留主题、目录搜索、静态HTML与提示词复制。

## 费用单凭证核对
费用卡突出金额与凭证状态，意见框留在同一审批视野。
什么时候用：出差费用凭证齐全后由主管决定。
什么时候别用：审批意见不替代财务票据真伪核验。
交互规则：金额1268元；凭证必须齐全且意见至少6字；同意后仅记录一次。
状态：费用单待主管 / 费用凭证未齐全 / 费用审批待确认 / 本机同意已记录

## 只处理待本人项
按节点筛出三条可批量处理的申请，其余单据展示不入选的原因。
什么时候用：主管在手机上集中处理低风险支出。
什么时候别用：财务复核和已退回单不应进入本人的同意批次。
交互规则：可批量3单共4804.50元；先核对再确认；不以全选覆盖非本人节点。
状态：批次范围待筛选 / 可审批三单已筛出 / 批次意见不完整 / 三单同意已记录

## 代理转交与责任
代理候选卡显示在岗状态和岗位，排除申请人及休假人员。
什么时候用：当前审批人即将休假，需要转交在岗同级主管。
什么时候别用：转交不表示费用已经被同意。
交互规则：申请人为叶澄；方衡休假；只允许在岗主管乔宁；转交理由至少6字。
状态：代理候选待选 / 代理身份不适用 / 转交信息已核对 / 审批已转交代理

## 退回补充材料
将缺失凭证和补充要求具体写给申请人，预览申请人收到的退回卡。
什么时候用：培训费用缺少签到表和场地原票。
什么时候别用：退回补充不是永久驳回该笔费用。
交互规则：材料名称必填、要求至少10字；确认后返回申请人节点。
状态：补充要求草稿 / 退回要求不具体 / 申请人退回卡预览 / 已退回申请人

## 审批节点轨迹
按时间线查看申请、主管、财务和出纳的处理意见，当前节点单独标记。
什么时候用：申请人想知道费用卡在哪一步。
什么时候别用：预计到账不应只根据主管同意判断。
交互规则：支持费用AP-8201与AP-8196；未知编号空结果；摘要下载保留节点意见。
状态：费用轨迹查询 / 申请编号不存在 / 财务复核进行中 / 审批轨迹已导出
