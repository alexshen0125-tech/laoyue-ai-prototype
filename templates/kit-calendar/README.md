## 用处

供产品经理、设计师和前端比较组件状态并拼可点击原型。组件用于基础任务，业务模块负责完整流程，页面模板组织多个模块。每个组件页面均提供具体何时用、别用及交互约束。

## 用法

1. 解压后双击 index.html，左侧搜索组件。
2. 顶部切换主题色、圆角、明暗；组件上方逐态查看，尺寸态并列小中大。
3. 一键复制HTML可取得当前状态的样式与静态结构。完整交互需迁移对应render/mount及依赖函数；片段不会自动包含业务事件。
4. 一键复制提示词可取得当前组件的用途、约束与状态。顶部AI提示词面板支持填写变量。
5. 免费下载按钮指向同目录kit-calendar.zip。

## 页面上的 AI 提示词

- 从零生成：重建本套画廊及完整状态。
- 拼业务页面：填写业务名称和页面类型，组织任务与失败恢复路径。
- 增加专用组件：填写组件名称和状态清单，沿用本套业务约束。
