# 会员营销活动

离线单文件交互原型。打开 index.html 使用；下载包包含页面及核验记录。标准外壳沿用 _kit。

## 会员人群圈选
以最近消费间隔筛选沉睡会员并呈现命中原因。
什么时候用：运营准备开展老客唤醒活动。
什么时候别用：新客获取不适用历史购买间隔。
业务状态：唤醒间隔待设 / 会员区间不合理 / 唤醒人群已圈选 / 活动人群已锁定
交互规则：间隔30至180天，当前样本按60天筛选。

## 优惠权益测算
同时展示满减门槛与预算可覆盖的领券人数。
什么时候用：优惠投放前核对活动权益成本。
什么时候别用：折扣叠加策略需单独评估毛利。
业务状态：权益参数待录 / 优惠门槛过低 / 券预算可承接 / 活动优惠券已配置
交互规则：优惠券面额1至50，门槛至少为面额3倍。

## 触达频次控制
将近期营销触达纳入免打扰判断。
什么时候用：会员已参加多场活动需要控制打扰。
什么时候别用：交易通知不计入营销活动次数。
业务状态：触达窗口待核 / 营销频次已达上限 / 会员可进入触达 / 触达批次已排队
交互规则：7天最多2次；已触达2次的人群不能再发送。

## 活动上线核对
用活动时间与权益准备情况控制发布入口。
什么时候用：营销方案确认后准备开启活动。
什么时候别用：此处发布只生成本地活动状态。
业务状态：上线条件待查 / 活动有效期错误 / 营销活动可发布 / 会员活动已开启
交互规则：结束日须晚于2026-11-11；权益必须已备妥。

## 活动效果归因
明确使用领券后7天内订单口径计算核销。
什么时候用：复盘活动转化并对齐统计范围。
什么时候别用：关联订单数不等于活动带来的净增量。
业务状态：归因窗口待选 / 归因口径偏离 / 活动数据可归档 / 营销复盘已封存
交互规则：7天核销120单，14天156单；归档需选择7天。
