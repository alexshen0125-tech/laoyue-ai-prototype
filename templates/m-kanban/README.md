# 任务看板 · 交互模块

免费下载 · 双击就能打开 · 复制提示词直接给 AI 用。

> 积木盒 · 老岳AI编辑部 · 原型组 | 单文件 HTML，离线可用 | 2026-11-10

围绕任务流转、容量、负责人和归档规则组织工作。适合产品经理画原型、对齐研发与测试。共5种做法、17个可切换状态。所有数据为示例，不向外部发送。

## 做法与场景

| 做法 | 状态 | 什么时候用 | 什么时候别用 |
|---|---|---|---|
| 状态流转与阻断 | 默认 / 缺少验收项 / 已完成 | 任务有明确的待办进行完成状态 | 强依赖表格批量录入的业务 |
| 在制品上限 | 有空位 / 达到上限 / 释放空位 | 团队要限制同时在做的任务 | 上限没有业务含义 |
| 按负责人泳道 | 全部 / 只看我 / 无人认领 | 同一流程需按负责人横向扫描 | 人太多导致横向纵向都难查找 |
| 卡片详情与编辑 | 查看 / 编辑中 / 校验错误 / 保存失败 / 已保存 | 任务需快速查看和修改 | 复杂审批和长篇文档编辑 |
| 归档与恢复 | 活动卡片 / 已归档 / 已恢复 | 完成任务较多但仍需查找 | 法定删除需求 |

## 用法

1. 下载 `m-kanban.zip` 并解压，双击 `index.html`，无需安装和联网。
2. 左侧搜索或选择做法，右侧切换状态，也可直接填写、勾选和点击操作。
3. 顶部可换主题色、圆角和明暗，点击 AI 提示词按钮打开提示词面板。
4. 每种做法可一键复制当前状态 HTML，包含样式与变量。与标杆相同，复制的是外观片段，不含完整交互逻辑；需要交互时复制对应提示词。
5. 示例数据一般仅保存在当前页面内存，刷新重置；主题偏好和反馈邀请的“不再邀请”保存在本机，可在页面恢复。

## 交互与恢复规则

| 做法 | 操作与反馈 |
|---|---|
| 状态流转与阻断 | 用移动按钮提供拖拽替代；未勾验收不能完成。 |
| 在制品上限 | 进行中最多两项；满额阻止移入，完成一项后释放。 |
| 按负责人泳道 | 按负责人分组，显示未分配；筛选不改变任务状态。 |
| 卡片详情与编辑 | 标题必填，保存失败保留输入；取消不覆盖原卡片。 |
| 归档与恢复 | 归档移出活动视图，可恢复；恢复到待办并明确告知。 |

处理中状态可直接查看，也可以从前一状态操作进入；模拟异步等待约0.65秒。切换做法状态会清理旧计时器。状态选择是演示入口，不代表真实业务后端。
