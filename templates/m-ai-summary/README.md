# AI 摘要核查

中文离线单文件。打开 index.html；顶部可下载本模块 zip。

## 原文与引用定位
摘要中的每个事实都连接到指定原文段落，避免只展示孤立结论。
什么时候用：会议和工单摘要需要回到证据检查数字与承诺。
什么时候别用：缺少原文时不能把生成文字标作已溯源事实。
状态：摘要带引文 / 原文已定位 / 引用源缺失 / 引用已恢复
交互：点击引用段落显示对应原文；移除来源后阻断无证据发布。

## 待核实结论
把原文未支持的推断从事实列表中剥离，让审核人逐条决定保留方式。
什么时候用：生成内容混合明确记录与模型推断的场景。
什么时候别用：不能用一个整体百分比替代逐项事实审查。
状态：结论待审 / 推断阻断发布 / 推断已标注 / 可发布结论
交互：仅原文支持的两条结论可直接保留；第三条需要删除或标记推断。

## 摘要长度与覆盖
在不同长度档位展示实际保留的要点，而非通过数值假算覆盖率。
什么时候用：同份会议记录要分别输出管理层速览与执行简报。
什么时候别用：压缩后遗漏决策条件时不可直接给执行团队使用。
状态：完整五条要点 / 短版两条要点 / 遗漏风险提示 / 长版已补全
交互：短版保留决策与日期，长版增加责任与风险；覆盖率仅按5条原文要点计数。

## 人工审核签审
审核人对摘要版本留下意见，退回与通过分别留下明确的处理轨迹。
什么时候用：对外发送前需由业务负责人确认表述。
什么时候别用：涉及专业结论时不能以AI生成代替负责人的审核。
状态：等待负责人 / 审核意见不足 / 退回修改 / 审核已通过
交互：审核人必选、意见至少6字；正文修改后原审核作废。

## 敏感信息与导出
导出前以遮罩文本替换联系人电话和邮箱，核对可分享范围。
什么时候用：需要把内部会议摘要发送给跨团队收件人。
什么时候别用：不应把遮罩当作对所有隐私类型的自动识别。
状态：内部原始摘要 / 脱敏预览 / 分享范围未选 / 文本已导出
交互：仅演示固定电话与邮箱脱敏；导出内容与预览一致，不上传外部服务。
