所有数据均为虚构示例，不联网；操作保存在当前页内存，刷新恢复。复制HTML是静态样式片段，完整操作需保留页面脚本。

## 制度多轮对话
保留用户问题与助手回答并显示轮次。
适用：员工连续追问报销制度细节。
不适用：离线固定答复不用于真实制度解释。
规则：输入4至200字；追加问题保留前文，Enter发送，Shift加Enter换行。

## 生成进度控制
展示检索与组织回答阶段，允许停止和继续。
适用：长回答生成时需要可撤回的等待反馈。
不适用：进度阶段不是模型内部推理记录。
规则：使用显式阶段按钮推进模拟；停止保留可见结果，不自动倒计时。

## 制度检索工具卡
检查检索工具参数与返回的制度条目。
适用：用户想了解回答引用了哪次检索。
不适用：工具成功不代表返回内容准确。
规则：范围限定费用制度；先运行后确认，失败可重试并显示调用次数。

## 制度引用溯源
点击回答中的来源后展示原文与适用日期。
适用：员工核对住宿限额的出处。
不适用：过期制度不得当作当前有效规定。
规则：五份来源各有版本；选择过期条目提示并禁止采信。

## 回答反馈与重试
登记赞同或问题原因，并切换重试版本。
适用：员工对制度回答提出修正线索。
不适用：负面反馈不会自动更改正式制度。
规则：点踩必须填写至少六字原因；重试保留原答复并递增版本。

## 对话上下文清空
清空前确认当前问题和来源将被移除。
适用：用户准备转到无关的新问题。
不适用：真实账户记录删除需要服务端支持。
规则：需输入清空；取消保留三条演示消息，确认只移除本页上下文，可开始新对话。
