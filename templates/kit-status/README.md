# 状态反馈组件库

用可解释的进度、节点和截止时间表达服务运行状态。

离线打开 index.html。示例数据均为虚构；除高级表单草稿外，业务修改仅在本次页面有效。

## 批次进度与重试
五批导入任务分别显示成功条数与失败条数。
适用：大文件导入需要理解局部失败。
不适用：未知总量任务应使用待估文字。
规则：重试仅处理失败7条；成功计数不得超过总量。
状态：导入进度跟踪、导入存在失败、失败记录可重试、导入批次完成、导入队列暂停、导入准备启动、导入计数核对、导入记录只读

## 开户步骤校验
以实名、绑定、验证和启用四个节点控制开户推进。
适用：用户需要清楚剩余开户环节。
不适用：可任意跳转的目录导航不适用线性步骤。
规则：每次推进一个节点；实名未确认不能进入绑定。
状态：实名资料待核、实名确认缺失、实名校验可过、账户步骤完成、银行卡待绑定、银行验证待核、账户准备启用、账户流程冻结

## 履约事件时间线
按明确时间排列下单、备货、出库和签收证据。
适用：订单履约需要追查节点先后关系。
不适用：未来计划不能混入已发生事件。
规则：可筛选异常；事件时间保持固定并展示时区。
状态：履约全量记录、履约异常筛选、异常处置待记、异常说明已存、履约入库视角、履约配送视角、履约签收视角、履约轨迹封存

## 服务健康度
五个依赖分别呈现可用率和最近探测结论。
适用：值班工程师判断服务降级来源。
不适用：样本探测不能当作生产监控。
规则：低于99.5%标记降级；恢复演示只改变支付依赖。
状态：依赖探测概览、支付依赖降级、依赖恢复待核、支付服务恢复、数据库探测视角、缓存探测视角、消息通道视角、依赖采样暂停

## SLA截止时间
把响应承诺写成固定截止日期与负责队列。
适用：工单需要解释何时必须首次回应。
不适用：截止文字不能当作实时告警服务。
规则：固定显示新加坡时间2026年11月12日18点；不运行跳秒计时。
状态：响应承诺待核、响应期限已逾、响应方案待记、首次响应已记、升级队列待接、客户等待说明、工作日口径说明、承诺记录封存

### 业务迁移

### 补齐边界
