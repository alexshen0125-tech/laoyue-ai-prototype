# 商品规格编辑

中文离线单文件，打开 index.html；顶部下载同名zip。保留主题、目录搜索、静态HTML与提示词复制。

## 规格售价矩阵
对选定口味组预览每个规格原价和新价，批量保存前展示差额。
什么时候用：饮品不同容量需要同组调价。
什么时候别用：采购成本调整不等同于零售价调整。
交互规则：售价0.01至9999且最多两位小数；选定原味组才影响两规格。
状态：规格调价草稿 / 目标售价不合规 / 原味组差额预览 / 两规格售价已更新

## 到货批次入库
给单规格登记到货批次，入库增加账面量但不改变锁单量。
什么时候用：仓库完成实物验收后补充可售库存。
什么时候别用：未验收的在途数量不能直接增加可售。
交互规则：燕麦奶账面128、锁单18；数量1至9999整数；批次号防重复。
状态：到货登记草稿 / 批次数量有误 / 到货已入账 / 同批次重复被拒

## 逐规格预警门槛
可售量扣除锁单后再与阈值比较，给零可售规格独立缺货标识。
什么时候用：商品运营排查同商品内的规格断档。
什么时候别用：低于阈值只提示补货，不自动下采购单。
交互规则：阈值1至999整数；原味110、可可12、冷萃0、气泡水183、红茶83。
状态：预警阈值草稿 / 阈值范围错误 / 规格预警已计算 / 预警配置已保存

## 单笔限购试单
在规格卡上试填购买数量，区分单笔限购与可售库存不足。
什么时候用：新品希望控制一笔订单买走的数量。
什么时候别用：单笔限购不能代替按账号周期限购。
交互规则：单笔上限1至100整数；可售量12；试单不得超任一门槛。
状态：限购配置草稿 / 订单超过单笔上限 / 规格可售量不足 / 试单数量可购买

## 规格停售影响核对
停售前列明未履约订单与剩余库存，订单处理完成才允许关闭售卖。
什么时候用：季节饮品退出销售但仍保留历史订单。
什么时候别用：停售不代表删除规格或抹去订单关联。
交互规则：待履约数非负整数；大于0阻断；原因至少6字；停售后保留91件库存。
状态：停售影响预览 / 仍有待履约订单 / 停售原因待补充 / 规格已停止售卖
