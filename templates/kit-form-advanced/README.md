# 高级表单组件库

把字段结构、显隐依赖与行级编辑放进可恢复的录入工作台。

离线打开 index.html。示例数据均为虚构；除高级表单草稿外，业务修改仅在本次页面有效。

## 动态字段编排
为入驻资料增加独立的联系人字段并允许撤销末项。
适用：收集不同数量的门店联系人。
不适用：固定税务字段不允许随意移除。
规则：最多五名联系人，至少保留一名；空姓名不能核验。
状态：联系人初建、联系人缺名、联系人可核验、联系人已核定、联系人扩展中、联系人达上限、联系人只读、联系人清空预览

## 企业条件显隐
用主体类型决定是否收集企业全称与统一代码。
适用：个人与企业共用入驻入口。
不适用：已签约主体变更须重新走审批。
规则：切换个人时清除企业值；企业全称至少四字。
状态：个人主体录入、企业名称缺失、企业资料可用、主体信息已提交、企业字段展开、个人字段收起、主体核验冻结、企业补件提示

## 省市网点联动
上级选项改变时清除城市和网点的旧选择。
适用：配送地址需要匹配服务网点。
不适用：自由文本海外地址不适用国内网点树。
规则：浙江对应杭州宁波，江苏对应南京苏州；网点由城市派生。
状态：配送省份待选、配送城市缺选、服务网点已匹配、配送区域已绑定、浙江节点展开、江苏节点展开、地址绑定锁定、服务树无选择

## 可编辑报价行
逐行维护物料数量并即时计算报价总额。
适用：供应商提交五种物料的报价数量。
不适用：财务发票金额需单独复核税额。
规则：数量0至999的整数；合计按各行单价乘数量。
状态：报价数量录入、报价数量越界、报价合计可核、报价版本已锁、首项数量调整、零数量备货、报价只读留底、数量待补齐

## 草稿保存与恢复
将项目名称和交付备注写入独立的本地草稿键。
适用：长表单需要关闭后继续填写。
不适用：多人协作不能依赖单机存储。
规则：保存与恢复显式触发；无草稿提示，损坏数据不覆盖输入。
状态：交付草稿编辑、交付名称不足、交付草稿可存、交付草稿已保存、交付草稿已恢复、本地草稿缺失、草稿存储受限、交付输入已清空

### 业务迁移
为{{配送表单}}建立省份城市网点联动，上级改变立即失效下级选择，给出缺选校验。

### 补齐边界
为{{报价工作台}}设计数量行编辑和草稿恢复，逐行计算价格，存储损坏时保留当前输入。
