# 空态、出错与反馈合集

单文件离线 HTML；所有业务数据均为虚构示例。适合在列表页评审前补齐异常情况，或为团队统一空态、出错和操作反馈规范。

## 用处

用同一份客户列表示例比较不同状态：空态告诉用户怎么开始，错误态提供恢复路径，反馈演示让评审看到确认、撤销、表单关闭等行为。

| 页面 | 可直达状态 | 数量 |
|---|---|---|
| 空态 `empty` | `normal` 首次使用、`filter` 筛选无结果、`search` 搜索无结果、`done` 已清空、`perm` 无权限 | 5 |
| 出错与异常 `error` | `loading` 加载、`slow` 慢加载、`offline` 断网、`500` 服务出错、`partial` 部分失败、`404` 不存在、`quota` 额度用完、`maintain` 维护 | 8 |
| 弹窗与反馈 `feedback` | `normal` 演示区、`danger` 危险确认、`drawer` 编辑抽屉 | 3 |

共 **3 页 / 16 态**；恢复后的正常列表、取消加载、申请已提交等为交互结果，不重复计入面板状态。

## 用法

1. 解压 `ui-states.zip`，双击 `index.html`；不需要服务器或依赖。
2. 右下角「原型面板」切页、切状态，按 H 隐藏；例如 `index.html#page=error&state=500`。
3. 修改脚本顶部 `DATA` 更换业务、列表数据、管理员、错误码及规则说明；修改 `:root` CSS 变量换主题。
4. 顶部「AI 提示词 · 一键复制」打开面板。第二条提示词中的高亮变量可点击就地填写，复制时自动替换。
5. 编辑抽屉保存仅作用于本次页面内的示例名称与负责人；刷新或重新选择原型状态时，部分演示状态会重置，不连接真实业务接口。

## 交互说明

| 元素 | 交互 | 反馈 |
|---|---|---|
| 左侧导航 / 原型面板 | 点击页面或状态 | 切换演示并更新地址片段 |
| 筛选条件标签 | 逐个去掉 / 清除筛选 | 条件清空后恢复三条示例数据 |
| 搜索无结果 | 输入后按 Enter / 清空搜索 | 回显搜索词；清空后恢复列表 |
| 无权限 | 申请权限 | 显示已申请与示例审批人 |
| 服务出错 / 断网 | 重试 | 先加载，再恢复列表示例 |
| 部分失败 | 重试这一块 | 仅恢复成交额卡片，其余数据保留 |
| 慢加载 | 取消 / 重新加载 | 显示取消结果，并可重新演示 |
| 错误码 | 复制 | 调用复制工具并提示结果；Chrome 实测复制成功 |
| 危险删除 | 输入指定示例名称 | 名称匹配才启用删除；删除仅演示反馈 |
| 普通确认 | 转交 / 取消 | 确认后显示示例转交反馈 |
| Toast | 成功 / 失败 / 归档 | 归档反馈含撤销入口；不修改真实数据 |
| 编辑抽屉 | 保存 / 取消 / Esc / 遮罩 | 名称必填；保存更新本次示例；未保存关闭前确认 |
| 维护横幅 | 显示 / 关闭 | 当前演示区显示或移除横幅 |
| 新建 / 导入 / 支持 / 升级等 | 点击 | Toast 明确标为示例入口，无真实外部跳转 |

## AI 提示词

下面内容与页面面板一致；带 `{{变量}}` 的部分可在面板就地填写。

### 1. 从零生成这个原型

请帮我做一个可点击的 PC 原型（1440 宽、1280 不横滚）：空态、出错与反馈合集。用同一个业务列表页（例：客户列表）演示所有状态，方便评审对着看。

1. 空态 5 种：首次使用（说明这里放什么 + 3 步上手 + 新建 / 导入）；筛选无结果（列出当前条件小标签，可逐个去掉，「清除筛选」）；搜索无结果（回显搜索词 + 换词建议）；已清空（正向反馈）；无权限（写谁能开通 +「申请权限」，申请后按钮变「已申请」）；
2. 出错与异常 7 种：加载中（骨架屏）；加载慢（超过 3 秒写正在等什么 +「取消」）；网络断开（顶部横幅，已加载内容仍可看，「重试」）；服务出错（不甩锅，错误码可复制，「重试」「联系支持」）；部分失败（只有一块卡片报错，其余正常，局部重试）；不存在（链接失效，「返回列表」）；额度用完 / 维护中（写清什么时候恢复或怎么升级）；
3. 弹窗与反馈：普通确认、危险确认（删除前要输入名称才能点）、Toast（成功 / 失败 / 可撤销）、抽屉表单有未保存修改时关闭要确认、页面顶部全局横幅；
4. 每个状态旁边附一张小表：什么时候出现 / 页面上写什么 / 给什么按钮。

状态（原型面板可切换）：12 种状态 + 反馈页。

设计要求：颜色、字体、圆角、间距写成 :root 变量，主色只用 --accent；图标内联线性 SVG；文案大白话，不说「系统异常请稍后再试」这种话；对比度 ≥4.5:1；弹窗抽屉 Esc 关闭、焦点锁定、关闭后焦点回到触发按钮；示例数据全部虚构；右下角「原型面板」切状态，按 H 隐藏，#page=xx&state=xx 直达。
硬性要求：单文件 HTML，不引用外部网址，双击离线可开；业务名称、示例数据、规则表集中在脚本顶部 DATA。
交付：① 完整 HTML；② 12 种状态规则表；③ 弹窗 / Toast / 横幅分别什么时候用的对照表。

### 2. 改成我的业务

附件是一个单文件 HTML 的空态、出错与反馈合集原型。请改成「{{页面，例如：订单列表 / 课程列表 / 工单列表}}」。

1. 只改脚本顶部 DATA 和文案；不要改 KIT 标记之间的共用样式和脚本，保留 12 种状态和弹窗反馈；
2. 首次使用的 3 步上手换成：{{3 步}}；无权限时找谁开通：{{角色 / 人}}；
3. 额度规则：{{例如：免费版最多 100 个}}；维护公告：{{时间}}；
4. 错误码格式：{{格式}}；示例数据标「示例」。
交付：改好的完整 HTML，加一张「状态 | 我的页面上写什么」表。

### 3. 在此基础上加页面 / 状态

附件是一个单文件 HTML 的空态、出错与反馈合集原型。请在它的基础上加：{{要加的页面或状态}}。

常见例子（选一个或照着写）：
- 「登录过期」：操作时提示「登录已过期」，重新登录后回到原页面，填了一半的表单不丢；
- 「并发冲突」：保存时别人刚改过，展示两边差异，选保留哪一份；
- 「移动端版本」：同样 12 种状态放进 390×844 手机框，空态插图缩小、按钮放底部。

要求：新状态加进「原型面板」；沿用现有 CSS 变量和组件样式；只改必要的地方。
交付：完整 HTML，加一张新增部分的「元素 | 交互 | 反馈」说明表。
