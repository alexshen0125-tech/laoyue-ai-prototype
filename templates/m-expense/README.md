# 员工报销

离线单文件交互原型。打开 index.html 使用；下载包包含页面及核验记录。标准外壳沿用 _kit。

## 发票查重登记
按发票号码定位重复报销，保留五张票据的来源。
什么时候用：员工整理本次差旅票据。
什么时候别用：这里只做本地查重，不提供税务验真。
业务状态：发票号码待录 / 发票已被占用 / 票据可加入报销 / 发票已入本次清单
交互规则：号码为8位数字，已登记82163017不可重复。

## 差旅标准核算
按出差天数核对住宿上限与超标部分。
什么时候用：住宿费用需要套用城市标准。
什么时候别用：交通包车不能使用住宿限额。
业务状态：住宿天数待核 / 差旅金额超标准 / 住宿额度可报销 / 住宿明细已核定
交互规则：住宿每天500元；天数1至30，金额大于0。

## 成本中心分摊
按项目比例拆分费用并显示两边金额。
什么时候用：一笔费用需由两个项目共同承担。
什么时候别用：不跨项目的报销无需拆分。
业务状态：分摊比例待录 / 项目比例越界 / 分摊金额已平衡 / 分摊方案已确认
交互规则：总额2400元，北区项目比例0至100。

## 报销退回补正
让审核意见指向缺少的出差说明材料。
什么时候用：财务需要向提交人解释退回原因。
什么时候别用：票据作废必须另行处理原始凭证。
业务状态：报销审核待决 / 审核意见过短 / 报销已退回补件 / 补正材料已送审
交互规则：意见至少8字；补正说明至少12字。

## 付款批次登记
把可付款报销单与银行回单编号绑定。
什么时候用：出纳完成付款后更新内部台账。
什么时候别用：页面登记不会实际发起银行支付。
业务状态：付款单据待核 / 银行回单格式错误 / 付款信息可登记 / 报销付款已记账
交互规则：回单编号须为RC加8位数字。
