# 数据导出审批

离线单文件原型，双击 index.html 打开。顶部提供同名zip免费下载。外壳直接采用 m-contract 的 _kit 标准。

## 导出范围预估
在生成文件前按时间范围评估数据量，防止无界导出。
什么时候用：运营需要提取有限时间窗口的订单明细。
什么时候别用：日常看板查询不应默认生成完整数据副本。
状态：导出范围待估 / 预计行数超上限 / 范围可进入申请 / 导出范围已锁定
交互规则：范围1至90天整数；每天估算1280行，超过5万行拆批。

## 敏感字段脱敏
让业务方预览列级脱敏结果，身份证等高风险字段不能明文流出。
什么时候用：订单导出涉及联系方式或身份标识。
什么时候别用：脱敏展示不代表取得数据处理授权。
状态：字段策略待选 / 身份证明文被拦截 / 脱敏样本可核对 / 字段策略已确认
交互规则：明文身份字段阻断申请；允许掩码或剔除。

## 导出用途与审批
用明确业务用途与审批人约束导出请求。
什么时候用：提取客户数据需要责任人审核。
什么时候别用：获得审批不能超出申请所列范围使用数据。
状态：导出用途待填 / 业务用途不充分 / 审批已拒绝 / 审批通过可制单
交互规则：用途至少10字；拒绝保留原因，通过才可制单。

## 限时下载与回收
在文件准备完成后生成有效窗口，过期后不可再用旧凭据。
什么时候用：审批通过的文件需要短期交付给申请人。
什么时候别用：公共外链不适合包含个人信息的导出文件。
状态：文件等待生成 / 下载凭据已过期 / 文件可限时下载 / 下载权限已撤销
交互规则：下载期限1至24小时；预览过期分支不可下载；撤销立即失效。

## 导出链路审计
把范围、审批、文件与访问放入同一条证据时间线。
什么时候用：安全人员需要复查一次导出的完整经过。
什么时候别用：日志缺失时不能宣称数据没有被访问。
状态：审计编号待检索 / 未找到导出审批 / 导出证据已汇总 / 审计摘要已封存
交互规则：仅接受EA-908；封存后下载本地审计摘要。

### 审核敏感列
围绕{{数据集}}列出敏感字段的样本与掩码方式，拦截身份证明文导出并保留审批用途。

### 控制文件访问
为{{申请人}}设计下载期限与撤销入口，把审批编号关联到文件生成、本人下载和审计封存。
