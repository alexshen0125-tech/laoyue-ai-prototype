## 实验流量分配
分开配置入组流量和组内A/B配额，明确未入组流量仍走基线。
什么时候用：新结账页只对一部分账号验证。
什么时候别用：同一实验中途改分组会污染已有样本。
交互规则：流量1至100；A加B等于100；展示各组占全量的比例。
状态：分流方案草稿 / 组内配额不平衡 / 分流比例已核对 / 实验配置已冻结

## 账号固定分组
按演示桶确定账号归属，重复检查同账号不会随机换组。
什么时候用：测试人员验证A组与B组界面入口。
什么时候别用：离线取模分组不用于正式随机实验。
交互规则：账号正整数；末两位小于50进A，否则进B；冻结后的账号分组不变。
状态：账号分组待查 / 账号编号无效 / 账号进入A组 / 账号进入B组

## 互斥层与冲突检查
同一用户层只允许一个结账实验占用，避免同时改变两个关键变量。
什么时候用：并行实验可能影响同一条结账路径。
什么时候别用：互不相干的业务层无需强制互斥。
交互规则：checkout层已有EXP-38占用；搜索层空闲；可保留排队申请。
状态：互斥层选择 / 结账层已被占用 / 空闲层可启动 / 实验已加入排队

## 转化观察与样本门槛
把转化率的分母和门槛摆在结论前面，避免小样本被误读为确定提升。
什么时候用：实验看板准备向负责人展示观察值。
什么时候别用：此处不执行显著性检验或自动择优发布。
交互规则：A为80/1000；B为98/1000；每组样本门槛正整数；结果仅观察差异。
状态：结果观察草稿 / 样本尚未达到门槛 / 可读取观察差异 / 观察记录已保存

## 护栏止损与结束
错误率突破护栏后停止新增入组，已有样本继续留存供复盘。
什么时候用：新版结账的失败率出现恶化。
什么时候别用：停止实验不会回滚已经创建的订单。
交互规则：B错误率2.4%；护栏0.1至10；停止原因至少8字；停后保留结果。
状态：护栏监测中 / 错误率触发止损 / 停止原因不足 / 实验已停止入组
