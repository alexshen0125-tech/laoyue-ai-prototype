# 表单搭建器

中文离线单文件，打开 index.html；顶部下载同名zip。保留主题、目录搜索、静态HTML与提示词复制。

## 字段顺序与稳定键
逐个移动字段而不改变字段键，右侧顺序即为填写顺序。
什么时候用：运营调整企业咨询的收集节奏。
什么时候别用：已有答卷的字段键不能随显示位置变动。
交互规则：首项上移会阻止；其他字段上移一位；保存后锁定排序。
状态：字段排列草稿 / 首项无法上移 / 字段顺序已调整 / 排列版本已保存

## 必填配置与错误文案
字段属性面板同时设置必填状态和缺失提示，避免只显示红星。
什么时候用：需要解释联系人信息为何必须提供。
什么时候别用：不要把选填营销偏好改为强制授权。
交互规则：必填字段必须有至少4字缺失提示；姓名示范为空时显示该文案。
状态：字段属性编辑 / 必填提示缺失 / 缺失错误预览 / 必填约束已保存

## 按客户类型显示税号
企业客户显示税号，个人客户隐藏该控件并跳过其必填检查。
什么时候用：同一入口接待个人和企业咨询。
什么时候别用：隐藏条件不应被用作敏感数据授权。
交互规则：企业税号18位字母数字；个人不检查隐藏税号；显示逻辑即时切换。
状态：个人路线预览 / 企业税号待补充 / 企业信息已校验 / 个人信息已校验

## 真实填写预览
预览使用实际姓名、邮箱和需求输入框，错误定位到用户正在填写的内容。
什么时候用：表单负责人检查客户侧填写体验。
什么时候别用：设计态拖拽操作不应出现在填写界面。
交互规则：姓名非空；邮箱格式校验；提交后保留本次填写回执，不真实收集。
状态：客户填写中 / 联系方式不完整 / 提交前内容核对 / 填写回执已生成

## 表单发布前检查
把标题、字段重名与草稿版本汇总到发布清单，避免空标题链接外发。
什么时候用：表单已完成填写侧预览准备交付。
什么时候别用：此原型的发布仅生成本地版本记录。
交互规则：标题至少4字；新增字段名不能与已有5字段重复；先检查再发布。
状态：表单版本草稿 / 发布检查未通过 / 版本检查已通过 / 表单版本已发布
