# 表单搭建器

中文离线单文件原型。解压后打开index.html，顶部下载本模块zip。

## 做法

- 字段排序：调整收集信息顺序；操作：将所选字段上移
- 必填配置：逐项配置必填约束；操作：保存所选必填字段
- 条件显示：企业客户展示税号；操作：配置企业字段条件
- 填写预览：预览真实填写体验；操作：校验本次填写
- 发布校验：发布前检查完整性；操作：发布当前表单版本

每种做法至少5条业务项，状态为默认、待确认、失败与重试、成功结果、空态。左侧目录可搜索，右侧有什么时候用/别用、复制当前HTML和提示词。顶部3条AI提示词支持填写变量；主题色、明暗和圆角保存本机。

## 交互规则

选择业务项、填写两个字段及至少5字说明，勾选核对后开始。先展示待确认摘要，再确认执行。修改输入或选择会使确认失效。失败保留输入，关闭失败开关后重试；取消恢复演示原记录。成功操作锁定，恢复演示可重开。状态按钮为独立预览，不代表真实操作。

金额单位元，时间基准2026-11-11、UTC+8，所有机构、人员及数据均为虚构业务示例。仅当前页面内存存储。复制HTML为含样式的静态当前片段，完整交互请使用单文件或提示词补齐。

## 模拟边界

不连接真实税务、支付、邮件、审批或AI服务。不实际上传证据、不访问引用网站、不公开发布表单。会员演示将成长值作为积分兑换样例余额，真实系统应独立建模积分账本；标签合并使用互斥演示对象计数，生产需按对象ID去重。服务端仍须实现权限、并发版本、幂等、持久化及审计。报表CSV为真实本地生成文件。
