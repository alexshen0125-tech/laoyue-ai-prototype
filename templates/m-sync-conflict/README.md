# 多端同步冲突处理

中文离线单文件，打开 index.html；顶部下载同名zip。保留主题、目录搜索、静态HTML与提示词复制。

## 本机覆盖前置版本
对比盘点草稿与服务器修订号，版本变化时停止覆盖。
什么时候用：本机盘点数量已经现场复核。
什么时候别用：不了解云端变更来源时先进行字段合并。
交互规则：基准版本12，服务器可模拟12或13；相等才允许写出版本13。
状态：本机草稿待同步 / 服务器版本已变化 / 覆盖差异已核对 / 本机稿已提交

## 采用云端并备份本机
丢弃本机改动前展示将被覆盖的文本，保存可恢复的本机副本。
什么时候用：确认服务器记录才是最新处理结论。
什么时候别用：不应在本机尚有未上传凭证时直接覆盖。
交互规则：备份原本机备注后采用云端v20；可从备份恢复为待同步稿。
状态：云端覆盖预览 / 本机副本已保存 / 云端v20已采用 / 本机副本已恢复

## 逐字段来源合并
把双方同时改过的联系电话与无冲突的地址分开决定。
什么时候用：多人离线修改同一会员资料。
什么时候别用：存在财务金额冲突时应转人工对账。
交互规则：电话必须选来源；地址取本机、偏好取云端；核对后生成合并v21。
状态：字段冲突待选择 / 电话来源未决 / 合并结果预览 / 合并版本已保存

## 同步退避与人工接管
连续网络失败逐步延后下一次尝试，达到上限后保留人工入口。
什么时候用：离线设备频繁重连产生重复同步。
什么时候别用：鉴权失败应重新登录而非网络重试。
交互规则：固定退避2、4、8秒，以模拟经过时间推进；3次失败转人工。
状态：等待网络重连 / 退避窗口未到 / 下一次尝试可执行 / 三次失败转人工

## 冲突快照与保留期限
把本机与云端原文封装为两份快照，解决后仍保留审计线索。
什么时候用：无法当场判断哪份售后备注更准确。
什么时候别用：快照不是已完成的云端同步结果。
交互规则：保留1至30整数天；保存编号后可标记人工解决，快照仍保留。
状态：快照保留设置 / 保留期限越界 / 双端快照已封存 / 人工解决已标记
