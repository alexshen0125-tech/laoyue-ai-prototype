# 移动端表单组件库

免费下载 · 双击就能打开 · 复制提示词直接给 AI 用。

在窄屏补货申请中处理选项、日期、地址、凭证和键盘遮挡。

打开 index.html 离线使用，数据为虚构，操作仅在本页有效。

## 门店底部选择器
打开底部面板从五家门店选择补货站点。
适用：店员单手录入补货申请。
不适用：超长组织树应使用搜索页面。
规则：临时选择需确认；取消不改变已选门店。
状态：补货门店待选、门店面板展开、临时门店已选、补货门店已定、门店选择取消、首店预览、末店预览、门店字段只读

## 到货日期滚轮
按年、月、日分列选择到货日期。
适用：门店预约下一批配送。
不适用：高频跨年查历史不适用滚轮。
规则：三列可键盘选择；拒绝不存在的日期。
状态：到货日期待选、日期组合无效、配送日期可用、到货日期已定、月份滚轮聚焦、日期滚轮聚焦、月底日期预览、日期设置只读

## 配送地址联动
切换城市后重新选择配送片区与详细地址。
适用：补货订单由城市匹配配送区域。
不适用：不覆盖未建档海外地址。
规则：城市变更清空片区；详细地址至少六字。
状态：配送地址待填、配送片区缺选、门店地址可用、配送地址已存、杭州片区展开、宁波片区展开、地址摘要预览、配送地址只读

## 到货凭证上传
在本机选择图片后显示文件名及容量。
适用：店员提交外箱异常凭证。
不适用：此原型不向云端上传图片。
规则：只接收PNG或JPEG且单张不超过5MB；可移除重选。
状态：凭证图片待选、凭证格式拒绝、凭证文件可用、到货凭证已挂、凭证容量超限、凭证文件已移、本地图片预览、凭证记录只读

## 补货申请步骤
依次核验物料、数量与提交摘要。
适用：门店需要拆开较长补货录入。
不适用：同屏短表单不必增加步骤。
规则：数量1至99；后退保留输入，提交锁定摘要。
状态：补货物料待填、补货数量无效、补货摘要待核、补货申请已交、补货数量录入、补货返回物料、补货明细预览、申请记录只读

## 键盘遮挡处理
备注聚焦后滚动到字段并预留底部操作空间。
适用：手机输入较长的收货要求。
不适用：桌面模拟不能证明真机键盘适配。
规则：使用visualViewport更新可视高度；备注至少八字。
状态：收货备注待填、收货备注过短、备注内容可交、收货要求已存、备注输入聚焦、键盘空间预览、备注输入退出、收货备注只读

## 从零构建
为{{门店补货}}设计门店选择器和日期滚轮，临时门店取消不写回，日期组合必须真实存在。

## 业务迁移
为{{配送申请}}实现城市片区地址联动和凭证上传，城市改变失效片区，限制图片格式及容量。
